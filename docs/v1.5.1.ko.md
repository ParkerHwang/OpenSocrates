# OpenSocrates v1.5.1: 중국어·일본어 지시문

[English](v1.5.1.md) · [한국어 README](../README.ko.md) · [简体中文](../README.zh.md) · [日本語](../README.ja.md)

v1.5.1은 기존 영어(`en`)·한국어(`ko`) 사고 콘텐츠에 간체 중국어(`zh`)와
일본어(`ja`)를 추가합니다. v1.6.0의 Go 전환·Windows ARM64 작업과 별개인
v1.5 유지보수 릴리스입니다.

## 콘텐츠와 호스트 범위

직접 작성한 사고 방법 48개마다 네 언어의 전체 절차와 정본 사례를 제공합니다.
전체 절차 파일은 192개입니다. 교사 질문 오버레이는 방법·언어마다 질문 3개씩
총 576개입니다. 번들과 오버레이는 콘텐츠 리비전 4를 사용하며, 원래 영어·
한국어 방법 본문과 개별 방법 리비전은 유지합니다.

기존 네 프로필에 번역한 컨트롤러·안내·참조를 제공합니다.

| 프로필 | 지원 환경 | 전달 방식 |
| --- | --- | --- |
| Codex | Apple Silicon Mac·Windows x64 | 기존 네이티브 패키지와 훅 |
| Claude Code CLI / Desktop 로컬 Code | Apple Silicon Mac | 상태를 저장하지 않는 네이티브 진입과 설치된 참조 |
| Claude 웹 / Desktop Chat / Cowork | Mac·Windows에서 계정 스킬 내보내기 | 실행 코드 없는 ZIP; 계정 업로드·활성화는 별도 |
| Antigravity 대화 앱 | Apple Silicon Mac·Windows x64 | 작업공간 또는 전역 규칙과 스킬 |

Windows Claude Code 네이티브 연동·Windows ARM64·Intel Mac·Linux 네이티브
지원 검증을 추가하지 않습니다. 과거 [Mac 안내](macos-v1.5.ko.md),
[Windows 안내](windows-v1.5.ko.md), [v1.5.0 인계](v1.5.0/PREPARATION_HANDOFF.md)는
날짜가 있는 증거를 유지합니다. 현재 README와 [설정 안내](setup-guide.ko.md)의
1.5.1 명령을 사용하세요. 번역·배포로 과거 관찰이 새 실사용 관찰로 바뀌지는 않습니다.

## 사고 지시문 언어 선택

유지되는 선택기에서 현재 입력의 언어를 결정하는 순서는 다음과 같습니다.

1. 현재 요청에 신뢰된 값으로 명시한 언어.
2. `en`·`ko`·`zh`·`ja`로 저장된 `locale_preference`.
3. 현재 입력을 일시적으로 읽는 문자 판별과 영어 기본값.

인식하는 히라가나·가타카나가 하나라도 있으면 문자 개수 비교 전에 일본어를
선택합니다. 그 외에는 한글이 우세하면 한국어, 한자가 우세하면 중국어입니다.
ASCII 문자가 우세하거나 동률·빈 입력·인식하지 못하는 문자이면 영어를 씁니다.
문자 판별은 사용자의 언어를 정확히 알아낸다는 보장이 아닙니다. 한자만 있는
입력은 중국어·일본어가 모호하므로 가나 없는 일본어에는 `ja`를 명시하세요.
번체 중국어는 별도 정본 언어로 제공하지 않으며 `zh` 지시문은 간체입니다.

저장한 선호는 네이티브 런타임 설정이며 npm 설치기 옵션이 아닙니다.
Mac의 설치된 Codex 패키지 루트에서 실행합니다.

```sh
bin/launch.sh locale codex get
bin/launch.sh locale codex set zh
bin/launch.sh locale codex set ja
bin/launch.sh locale codex set follow
bin/launch.sh locale codex reset
```

Windows x64에서는 패키지의 Node 실행기를 사용합니다.

```powershell
node bin/launch.mjs locale codex get
node bin/launch.mjs locale codex set ja
node bin/launch.mjs locale codex reset
```

`follow`와 `reset`은 저장된 언어 선호를 해제하여 현재 입력 판별을 사용할 수
있게 합니다. 무관한 설정은 지우지 않습니다. 저장소의 고정된 개발 환경에서는
다음 소스 진입을 사용합니다.

```sh
uv run --locked python -m opensocrates locale get
uv run --locked python -m opensocrates locale set zh
uv run --locked python -m opensocrates locale reset
```

기존 SDK 선택기 경로는 Windows에서 사용할 수 없습니다. 저장 설정은 상태를
저장하지 않는 판단 경로나 계정·콘텐츠 패키지를 변경하지 않습니다.

### 상태를 저장하지 않는 판단 요청

판단 요청에는 JSON `locale`을 `en`·`ko`·`zh`·`ja` 중 하나로 명시해야 합니다.
저장 설정을 읽거나 대화에서 언어를 추정하지 않습니다. Codex 패키지 루트에서
Mac은 `bin/launch.sh decision codex`, Windows는
`node bin/launch.mjs decision codex`에 기존의 닫힌 요청 형식을 전달합니다.
요청의 `locale`을 원하는 언어로 바꾸고 지원하지 않는 `--locale` 옵션을 추가하지
마세요. 패키지의 `skills/opensocrates/references/decision/request.json`에 전체
예시가 있습니다. 라우팅 특징은 충족하지 못한 전제까지 실제 작업을 반영해야
하며 언어 변경으로 방법의 적용 조건을 우회할 수는 없습니다.

Claude 네이티브 패키지는 `bin/launch.sh decision claude`를 사용합니다.
계정 스킬·Antigravity 콘텐츠는 해당 언어 안내·카탈로그와 전체 참조를 읽으며
로컬 선호 저장소를 사용하지 않습니다. 모호한 입력에서는 에이전트에게 간체
중국어 또는 일본어 OpenSocrates 지시문을 쓰라고 명시하세요. 모델이 선택하는
계정 스킬은 여전히 불러오기에서 누락될 수 있습니다.

사고 지시문 언어는 답변 언어·호스트 화면 언어·npm 설치기 출력과 별개입니다.
모든 CLI 메시지가 번역됐다고 주장하지 않습니다. 방법 ID·JSON 키·사용 표기
문구는 언어가 바뀌어도 유지합니다.

## 설치·업데이트·활성화

Node.js 20 이상과 호스트의 정상 로그인·권한 흐름을 사용하세요.

```sh
npx --yes opensocrates@1.5.1 install --host codex
npx --yes opensocrates@1.5.1 update --host codex
npx --yes opensocrates@1.5.1 status --host codex
```

처음 설치할 때는 `install`, 기존 설치에는 `update`를 선택합니다. 네이티브
런타임은 포함되어 있습니다. Mac에서는 `--host claude`, 지원 플랫폼에서는
`--host antigravity`를 명시하세요. 작업공간 설치·상태 관리에는 같은 절대 경로의
`--workspace`를 사용합니다. 기본값과 `--host all`은 계속 Codex만 선택합니다.

계정 스킬은 이미 존재하는 폴더의 ZIP 절대 경로로 내보냅니다.

```sh
npx --yes opensocrates@1.5.1 export --host claude-chat --output /absolute/path/to/opensocrates-1.5.1-account.zip
```

교체 전 기존 스킬과 활성화 상태를 백업하세요. 사용하는 Claude 계정에 새 ZIP을
업로드하고 켭니다. 설정 안내의 상시 지침을 추가할 때 기존 계정 지침은
보존합니다. 내보내기 성공은 계정 설치·활성화가 아닙니다. 실제 호스트의 신뢰·
권한을 검토하고 의도적으로 꺼둔 설치는 보존하며 변경 후 새 대화를 시작하세요.

## 사용 표기·개인정보·증거

적격한 정본 방법 전체를 읽고 해당 답변에 실제 적용했을 때만 마지막에
`Powered by OpenSocrates`를 정확히 한 줄로 표시합니다. 네 언어 모두 같은
영어 문구를 사용합니다. 독자 안내만 사용하거나 기계적인 작업만 했다면
표시하지 않습니다. 이 문구 자체는 네이티브 적용이나 결과 개선의 증명이 아닙니다.

언어 추가로 텔레메트리·자격 증명 수집·원시 프롬프트나 대화 저장·스크린샷
보관·숨겨진 추론 수집을 도입하지 않습니다. 문자 판별은 현재 텍스트를
일시적으로 사용합니다. 상태 없는 판단 조회는 사적인 대화를 읽거나
데이터베이스를 만들지 않습니다. 일반 호스트 요청에는 호스트의 인증·권한·
보관 설정·약관이 적용됩니다.

구현·로컬 검증·배포 검증·실제 호스트 관찰은 서로 다른 증거입니다. 번역 대응과
배포 파일 검증은 모든 계정의 활성화·매 턴 적용·보편적인 답변 품질이나 토큰
비용·속도 향상을 증명하지 않습니다. 일반 설치 완료에 보편적인 모델 답변
시험을 추가 필수 조건으로 요구하지 마세요.
