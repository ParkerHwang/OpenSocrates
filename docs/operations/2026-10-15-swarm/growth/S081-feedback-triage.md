## 관찰하지 않은 자료와 접근 한계

지정된 다섯 GitHub 대화는 모두 접근 가능했다. GitHub 웹 PR 페이지에 일부 UI 로딩 오류가 표시되어, 댓글·리뷰·스레드의 누락 여부는 읽기 전용 GraphQL의 전체 페이지 메타데이터로 확인했다. 페이지 오류 자체를 댓글이 없다는 근거로 사용하지 않았다.

#113에 연결된 다른 사이트의 현재 대화는 **unavailable for this observation**이다. F001/F002 등 Reddit 대화, izanami, 두 GPTers 사례, LinkedIn, X/Threads, Product Hunt의 현재 답글·알림·개인 피드·계정 활성 상태는 직접 조회하지 않았다. 이 표의 “새 요청 없음”을 그 사이트나 모든 사용자에게 확대할 수 없다.

보존할 상태는 [15 October 후속 인계](https://github.com/ParkerHwang/OpenSocrates/issues/113#issuecomment-6182771759)에 보고된 기존 [X CSV 게시물](https://x.com/ParkerHwang/status/2110142877187871110), [Threads 소개](https://www.threads.com/@theparkerhwang/post/Deb_uxREibV), 그리고 소유자 최종 게시가 예약된 Threads 회의 메모 팁이다. 전자는 유지관리자가 게시를 확인한 과거 기록이며, 예약 팁은 게시·저장 상태 미확인이다. 이번 작업은 소셜 상태를 새로 검증하지 않았고 재게시·재열기·bump를 제안하지 않는다.
