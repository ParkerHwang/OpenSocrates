# 설치와 런타임 참고

[English](advanced-usage.md) · [네이티브 명령](native-v1.6.ko.md)

미출시 v1.6.0 후보는 Go 네이티브 실행과 GitHub Release 직접 배포를 사용합니다.
사용자는 호스트 앱과 승인된 자산만 필요하며 Python·Node.js·npm·Go가 필요하지
않습니다. 설치·인수·갱신·검증·내보내기·제거, 자동업데이트, 저널 복구 명령은
네이티브 안내를 따릅니다. 기본값과 `--host all`은 Codex만 선택합니다. Windows
네이티브 Claude Code와 추가 플랫폼은 이번 범위 밖입니다.

## 신뢰·비활성 상태·적용

대화형 Codex의 `/hooks`에서 훅 7개를 검토하세요. 비대화형 `codex exec`는
미승인 훅을 건너뛸 수 있습니다. 인수·갱신은 신뢰와 비활성 상태를 보존합니다.
원할 때 명시적 호스트 제어로 켭니다. 계정 ZIP 내보내기와 업로드·활성화는
별도입니다. Antigravity 전역/작업공간 등록은 명시적이며 새 버전은 새 세션이나
reload가 필요할 수 있습니다. `status`·`manage diagnose`는 로컬 목록·등록을 확인하며
실제 방법 적용을 증명하지 않습니다.

## 런타임 동작

Codex 훅은 가벼운 탐색 안내를 제공합니다. 활성 에이전트가 달라진 판단에 방법이
필요한지 결정하고 적격한 정본 전체를 읽습니다. 일반 경로는 추가 모델·인증
호출이 없습니다. `decision codex --stream`은 해당 프로세스 메모리에 조회 상태를
유지하며 새 프로세스·문맥은 읽기 주장을 물려받지 않습니다. wire 계약은
[판단 지점 조회](decision-points.ko.md)를 따릅니다.

이전 선택기는 고정 외부 Codex app-server 프로토콜의 별도 Go 어댑터입니다.
인증·문맥 격리, 제한된 읽기 도구, 기한·취소·정리를 유지합니다. 안전하지 않거나
사용 불가·버전 불일치라면 사용자 작업을 막지 않습니다. 삭제하거나 일반 훅에서
자동 호출하지 않습니다. Windows의 인증 복사·POSIX 문맥 사용 불가 경계도
유지합니다.

v1.5.0 리비전 3 기준의 48개 방법·영어/한국어 의미·교사 질문·응답·공통 안내를
보존합니다. 본문 개선은 포함하지 않습니다. 잘못된 라우팅을 scope 변경 전에
거부해 이전 가용 상태를 보존하는 것은 의도한 변경이며 다른 wire·저장 상태
의미는 호환 리팩토링으로 유지합니다.

## 소유권과 복구

적용 전에 검증한 전체 목록으로 바이트를 묶습니다. 설치·갱신·제거는 저널과
공통 작업·복구 엔진을 사용하며 전달·등록·OS 보호는 분리합니다. 안전한 복구가
불가하면 다른 소유자·수정 파일·미확인 잠금·백업을 보존합니다. 명령 성공을 위해
소유권·ACL·reparse·동시성 검사를 우회하지 마세요. 업데이트 소유자는 하나이며
명시적 npm 인수는 이전 예약 작업을 조정하고 관련 없는 패키지·데이터는 지우지
않습니다.

Codex 선택적 안정 갱신은 훅 밖에서 사용자 Mac LaunchAgent·Windows 작업
스케줄러를 사용합니다. 서명된 메타데이터의 신뢰 루트·만료·롤백·플랫폼·목록·
호환성을 확인해야 합니다. 메이저·비호환 스키마는 자동 적용하지 않습니다.
운영 신뢰·서명은 후보의 남은 릴리스 조건이며 다른 프로필은 수동 관리합니다.

## 증거와 개발

소스는 `src/opensocrates/`, 방법은 `content/methods/`, 스키마는
`schemas/source/`, 템플릿은 `plugin-src/`에 있습니다. 출력은 생성하고 직접
수정하지 않습니다. [기여 안내](../CONTRIBUTING.md)에 따라 전체 구현·통합 후
최종 검사합니다. 네이티브·새 기기·같은 기기 재설치·인증된 호스트·공개 릴리스
증거는 별개이며 과거 증거는 당시 버전에 한정됩니다. 비보관·안전한 통과 경계는
[보안 정책](../SECURITY.md)을 따릅니다.

중복 JSON 키·짝 없는 Unicode surrogate 거부는 의도한 보강입니다. 전체 요청을
문맥·scope 변경 전에 검증하고 안전하지 않거나 모르는 새 설정을 기본값으로
덮어쓰지 않습니다. 컴파일 콘텐츠는 `product_version`만 `1.6.0`으로 바꾸며
방법·projection·정책은 리비전 3입니다. 이전 호환 경로는 opt-in·외부 Codex
`0.144.4` 고정이며 가용성이 인증된 실제 증거는 아닙니다. 설치 진단은
`manage diagnose --host HOST`로 기존 런타임 `diagnose codex`와 구분합니다.
