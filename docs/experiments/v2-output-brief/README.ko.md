# Output Brief: OpenSocrates 2.0 후보

특정 독자를 위한 메시지·보고서·의사결정 문서 작성을 돕는 독립적인 실험용 스킬 후보다. 사용자에게 쓸 수 있는 결과물을 제공하면서 중요한 사실과 불확실성, 사용자가 정한 선택을 보존하도록 안내한다. 선택적인 Python 텍스트 검사는 사용자가 제공한 자료와 초안의 일부 표면적 차이를 표시한다. 스킬과 검사는 메시지를 보내거나 자료를 별도로 저장하지 않으며, 호스트 자체의 처리는 별개다.

검사는 문장 의미나 외부 사실을 증명하지 못한다. 오류를 놓치거나 올바르게 계산한 수치를 표시할 수 있다. 표시는 사람이나 원자료를 통한 확인을 돕는 단서이며, 표시가 없다고 초안이 정확하다는 뜻은 아니다. 검사기는 Claude가 합성 자료로 만든 `rulelab` 시제품에서 가져왔고 이 저장소에서는 아직 독립적으로 검증하지 않았다.

실험용 패키지에는 실행 가능한 Python 스크립트가 들어 있다. 원본은 [`evidence_scan.py`](../../../plugin-src/experimental-output-brief/skills/output-brief/scripts/evidence_scan.py)다. 사용자가 검사 결과를 받을 때 실제 스크립트 실행과 직접 대조를 구분하고, 빠지거나 바뀐 입력을 밝히며, 이후 수정된 초안에 예전 검사 결과를 그대로 적용하지 않아야 한다.

완성된 2.0 제품이나 답변 품질 개선의 증거는 아니다. 공통 스킬 원본은 [`plugin-src/experimental-output-brief/skills/output-brief`](../../../plugin-src/experimental-output-brief/skills/output-brief/SKILL.md)에 있다. 스킬 파일을 제공했다는 사실만으로 호스트가 발견·활성화했고 모델이 읽거나 사용했다고 단정하지 않는다.

## 실험용 패키지

저장소 루트에서 `python3 docs/experiments/v2-output-brief/package.py`를 실행하면 같은 스킬 원본으로 OpenAI 형식 플러그인과 Claude 스킬 ZIP을 `build/experiments/v2-output-brief/`에 만든다. 공개되지 않은 실험용 패키지이며 2.0 릴리스가 아니다. 파일 생성만으로 설치하거나 활성화하지 않는다.

- OpenAI 패키지는 문서에 나온 [플러그인 구조](https://developers.openai.com/plugins/build/plugins)를 따른다. 로컬 설치나 디렉터리 배포는 대상 환경에 따라 다르다.
- Claude는 **Customize → Skills**에서 스킬 폴더가 들어 있는 ZIP을 업로드하는 방법을 안내한다. 계정과 코드 실행 조건은 [Claude 스킬 사용 안내](https://support.claude.com/en/articles/12512180-use-skills-in-claude)를 참고한다.

두 패키지는 아직 실제 호스트에서 사용을 검증하지 않았다. 실험 폴더 `plugin-src/experimental-output-brief/`에 별도 로컬 플러그인 목록을 두었다. 목록을 등록하는 것만으로 설치되거나 활성화되지는 않으며 기존 1.x 목록은 바뀌지 않는다. 별도 임시 설정의 Codex CLI에서는 설치가 성공했고 설치된 파일이 `c8e1815`의 후보와 일치했다. 이 관찰은 ChatGPT나 다른 계정에서의 활성화·사용을 뜻하지 않는다. 제공 여부는 요금제·계정·조직과 사용 화면에 따라 다를 수 있다.

저장소를 내려받은 환경의 Codex CLI에서는 별도 실험용 목록을 등록하고 후보만 설치할 수 있다.

```sh
codex plugin marketplace add ./plugin-src/experimental-output-brief
codex plugin add opensocrates-output-brief-experiment@opensocrates-output-brief-experiment-local
```

이 명령은 실행하는 사용자의 로컬 Codex 설정을 변경한다. 더 이상 필요하지 않으면 실험용 플러그인과 해당 목록만 제거하고 기존 OpenSocrates 설치는 유지한다. 격리된 설치 시험은 로그인된 세션에서 실제로 사용된다는 증거가 아니다.

```sh
codex plugin remove opensocrates-output-brief-experiment@opensocrates-output-brief-experiment-local
codex plugin marketplace remove opensocrates-output-brief-experiment-local
```

기여자는 `make v2-candidate-check`로 점검기·연결 코드·프로세스 경계와 합성 벤치의 오프라인 검사를 실행할 수 있다. 이 명령은 모델을 호출하거나 호스트 설치를 검증하지 않는다.

호환되는 호스트에서 스킬을 불러온 뒤에는 대화에 제공한 자료와 초안의 비교를 요청할 수 있다. 호스트가 Python 실행과 표준 입력을 지원하면 자료를 파일로 먼저 저장하지 않고 검사에 전달할 수 있다. 그렇지 않은 호스트에서는 자료를 직접 대조할 수 있으며, 이때 스크립트 검사가 실행된 것은 아니다. 검사기 자체는 입력을 저장하지 않지만 대화와 도구 데이터에 대한 호스트의 보관 방식은 별개다.

검사는 따로 제공된 근거 자료만 초안과 비교한다. 요청문에는 초안이 인용될 수 있으므로 요청문 자체를 근거로 쓰지 않는다. 한 메시지에 자료와 초안이 함께 있으면 호스트가 자료를 분리해야 하며, 분리할 수 없다면 검사를 마쳤다고 주장하지 않아야 한다. 검사기는 제공된 자료 안에 초안이 섞이지 않았다는 사실까지 보장하지 못한다.

초안 전체가 자료에 그대로 포함되면 순환 대조 가능성을 표시하지만, 일부나 바꿔 쓴 내용까지 모두 찾아내지는 못한다. 어떤 자료가 최신인지, 확정됐는지, 폐기됐는지, 단지 제안인지도 판단하지 못해 오래된 값이 존재한다는 이유로 일치한 것처럼 보일 수 있다. 자료 선택과 의미는 별도로 확인해야 한다.
조건이나 미래 표현은 현재 확정 주장으로 표시되지 않더라도 승인되지 않은 약속일 수 있다.

[부정 표현 사례](cases/negation.json)는 Claude가 규칙을 설계하면서 만든 합성 회귀 사례다. 독립적인 정확도 측정이나 실제 글의 대표 표본이 아니다.

## 가상 요청으로 사용해 보기

같은 모델과 호스트의 별도 대화에 같은 요청과 사실을 주고 한 번은 이 스킬 없이, 한 번은 스킬을 활성화한 상태로 진행한다. 호스트가 허용하는 범위에서 조건을 맞추고 스킬의 정확한 내용, 모델, 호스트와 실제 제공 여부를 기록한다. 한 번의 비교는 예시이며 일반적인 효과가 아니다. 실제 비공개 업무를 공개 평가나 저장소에 올리지 않는다.

> 방문자에게 보낼 짧은 영문 워크숍 이메일을 작성해 줘. 수용 인원은 24명이고, 장소는 아직 검토 중이야. 사진 촬영에 동의한 사람은 없어. 참석 의향을 물어봐 줘. 나에게 남길 질문은 한국어로 알려줘.

사용 가능한 이메일은 장소 예약이나 촬영 동의가 확정됐다고 쓰지 않으면서 참석 의향을 물을 수 있다. 요청자에게 남기는 메모는 한국어, 이메일은 영어로 작성할 수 있다. 특정 단어의 등장 여부만이 아니라 정확성, 명확성, 실제 사용 가능성, 질문과 소요 시간을 비교한다. 이 요청만으로 스킬이 발견되거나 실제 사용됐다고 볼 수는 없다.

이 후보는 개인 규칙 후보 및 공개 벤치마크 제안과 함께 공동 검토하기 위해 준비했다. 호스트 연결, 벤치마크 결과, 사용자 채택이나 기본 모델보다 우수하다는 주장은 없다.

실험용 [`tools/v2_codex_bench_adapter.py`](../../../tools/v2_codex_bench_adapter.py)는 공개 합성 벤치를 이미 로그인된 로컬 Codex CLI와 연결할 수 있다. 임시 폴더의 일회성 세션에서 도구를 쓰지 말라고 요청하고, 관찰한 도구 이벤트가 있으면 결과를 거부한다. 모든 읽기나 네트워크 접근이 기술적으로 차단된다는 뜻은 아니므로 공개 합성 사례만 쓴다. 안내문은 직접 전달하며 플러그인 설치·스크립트 제공·호스트의 스킬 발견·읽기·적용을 증명하지 않는다. 명령 출력은 벤치에서 모델 호출을 검증한 영수증이 아니다. 모델 신원과 계정·호스트 상태도 별도 확인이 필요하다.

연결 코드는 사례의 `public_synthetic: true` 표시를 요구한다. 이는 작성자의 표시일 뿐 실제로 공개 합성 자료라는 인증은 아니다.
