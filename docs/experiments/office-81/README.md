# 사무 업무 81 담당자 실험

가상의 사무 업무 한 건을 대상으로 9개 업무 능력 × 9개 질문을 81개의 독립 AI 호출로 시험하는 초기 연구용 실험이다. OpenSocrates 제품이나 출시 기능이 아니다. Codex CLI를 실행 환경으로 사용한다. Claude, ChatGPT 웹 등 다른 호스트에서의 동작을 의미하지 않는다.

## 구성

- `agents.json`: 81명 각각의 질문과 역할.
- `case.json`: 개인·회사 정보가 없는 가상 업무 사례와 확인할 결과.
- `run.py`: 독립 호출을 동시성 제한 안에서 실행하고, 기본 응답 및 종합 응답을 생성하는 실험 진행자.
- `test_harness.py`: 실험 진행자의 기본 동작과 실패 처리를 확인하는 테스트.
- `FIRST_RUN.md`: 첫 실행 결과와 Claude의 익명 비교, 관찰 범위.
- `results/`: 실행 결과를 저장하는 로컬 전용 폴더. Git에 포함하지 않는다.

각 능력 안에서는 9명의 결과가 순서대로 이어지고, 서로 다른 능력의 작업은 동시성 제한 안에서 병렬로 진행한다. 모든 능력이 고정된 순서로 이어지는 단일 81단계 흐름은 아니다. 마지막 종합 호출이 실제 성공한 답변을 모아 사용자 결과를 만든다. 각 질문의 고유한 관점은 검토하지만 독립 호출의 협업 효과나 실제 업무 성과는 별도 검증이 필요하다.

## 실행

Codex CLI 및 해당 계정의 사용 가능 상태가 필요하다. 모델 호출 횟수와 시간, 사용량 제한에 영향을 줄 수 있다. Codex CLI는 기존 로그인으로 요청한다. 다른 별도 API 키를 수집하지 않는다.

```sh
cd docs/experiments/office-81
python3 run.py --dry-run
python3 run.py --output results/run.json --concurrency 6
```

가상 데이터만 사용한다. 실제 이메일, 메시지, 고객 정보나 기밀 업무 내용을 넣지 않는다. 실행 요청과 대화 기록은 저장하지 않으며, 로컬 결과에는 가상 사례에 대한 공개 응답과 상태만 담는다. 메일 발송, 예약 등 외부 행동은 하지 않는다. 실패 또는 시간 초과는 성공으로 채우지 않는다. 도구 사용은 출력 이벤트에서 사후 감지해 해당 결과를 거부한다. 이 감지는 도구 실행 자체를 막는 장치가 아니며 읽기 전용 설정만으로 파일 읽기나 네트워크 접근이 전부 차단되는 것도 아니다. 실제 자료를 쓰려면 별도의 격리와 정책 검증이 필요하다.

기본 응답과 81명 종합 응답의 유용성을 평가할 때는 `case.json`의 확인 항목 외에도 목적 적합성, 우선순위, 맥락, 사실의 정확성, 이해하기 쉬운 전달, 수정 부담을 함께 살펴본다. 한 가상 사례의 결과는 일반 사무직 전체에 대한 효과나 81명 구조의 우월성을 입증하지 않는다. 결과가 쓸 만한지 사람의 판단이 필요하다.
