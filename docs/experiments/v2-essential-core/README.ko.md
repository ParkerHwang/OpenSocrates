# OpenSocrates 핵심 실험

작고 독립적인 2.0 후보입니다. 사용자가 일을 진행하도록 도우면서 확인된
내용과 가정·미정을 구분합니다. 중요한 선택에는 무엇을 얻고 포기하는지,
어떤 사실이 판단을 바꿀 수 있는지 설명하고, 단순한 일에는 절차를 강요하지
않습니다.

후보 전체는 [`SKILL.md`](../../../plugin-src/experimental-core/skills/opensocrates-core/SKILL.md)
한 파일입니다. 스크립트, 도구, 훅, 설치 프로그램이나 사용 기록 수집 기능이
없는 일반 텍스트입니다. 내용을 직접 읽어 지침으로 쓰거나, 스킬을 지원하는
호스트에 해당 호스트의 방법으로 제공할 수 있습니다. 이 저장소는 아직 설치용
패키지를 제공하지 않습니다. 이 후보는 1.x 사고 방법 라이브러리를 호출하지 않습니다. 개별 방법
연결은 향후 작업이며 현재 기능이 아닙니다. 기존 1.x 파일은 바꾸지 않았습니다.

이전 [output-brief 실험](https://github.com/ParkerHwang/OpenSocrates/pull/164)은
검사기와 벤치마크를 포함해 별도로 보존하며, 이 후보에는 포함하지 않습니다.
이것은 실험이며 정식 릴리스가 아닙니다. 일반 모델이나 짧은 지시보다 결과가
개선됐다는 증거도 아직 없습니다.

## Codex에서 로컬 스킬 사용해 보기

`opensocrates-core` 스킬 폴더를 사용할 프로젝트의 `.agents/skills/` 폴더에
복사하고, 그 프로젝트에서 새 Codex 세션을 열어 작업과 함께
`$opensocrates-core`를 명시적으로 요청합니다. 같은 이름의 폴더가 이미 있다면
복사 전에 백업하거나 다른 프로젝트를 선택하세요. 실험을 제거하려면 복사한
폴더를 지우면 됩니다.

Codex CLI 0.166.0-alpha.5.1의 임시 프로젝트에서 `$opensocrates-core`를 명시해
요청했을 때, 복사한 스킬 파일을 성공적으로 읽고 가상의 선택 과제에 답변하는
것을 한 번 확인했습니다. 이 관찰은 자동 발견, 실제 적용, 일반적인 유용성이나
다른 호스트에서의 동작을 입증하지 않습니다.

## 선택에 사용해 보기

> 클라우드 도구를 구매하려 했는데 업무가 오프라인에서 돌아가야 해요.
> 구매, 직접 제작, 임시 수작업을 비교해 주세요. 도구의 오프라인 지원 여부와
> 팀이 자체 도구를 유지할 수 있는지는 아직 몰라요.

유용한 답변이라면 오프라인 지원, 인력, 수작업 가능성을 사실로 가정하지 않고
선택지를 비교할 수 있습니다. 미정인 내용과 관계없이 할 수 있는 작은 다음 행동과
판단을 바꿀 조건도 알려줄 수 있습니다. 위 문장은 사용 예시이며 실제 실행
결과가 아닙니다.

답변을 비교한다면 별도 대화에 같은 요청과 맥락을 주고, 지침이 없는 경우와
짧은 일반 지시를 준 경우도 함께 살펴보세요. 스킬 내용이 실제로 모델에 전달됐는지,
답변이 도움이 되는지, 추가 지침이 오히려 방해되는지 확인합니다. 사례 하나만으로
일반적인 효과를 결론 낼 수는 없습니다.
