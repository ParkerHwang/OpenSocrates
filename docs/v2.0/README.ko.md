# OpenSocrates 2.0 준비 자료

지금 만들 범위는 [핵심](CORE.ko.md)입니다. 수신자를 위한 산출물, 초안이 쓰는 사실을 되돌리는 이어 하기, 그 범위를 만든 뒤에 증명할 Cursor 경로 하나입니다. [English core](CORE.md)가 같은 범위를 적습니다. 이 디렉터리는 개발 착수 패킷도 유지합니다. 패킷에는 더 넓은 제품 방향, 구현 조사, 검증 기준, 기존 작업의 인계가 있습니다. 이 자료 자체는 제품 구현이나 출시가 아닙니다.

Cursor는 2.0의 필수 신규 지원 대상입니다. Bot은 별도 작업 흐름으로 준비하며 서비스별 출시 주장은 실제 접근과 검증에 따릅니다. 기존 1.6 PR과 이슈는 종료하되 브랜치와 검증 이력은 보존하고, 재사용은 검토 후 선택합니다. 이 자료나 이전 작업의 종료만으로 제품이 출시된 것은 아닙니다.
