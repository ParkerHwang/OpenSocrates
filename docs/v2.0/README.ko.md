# OpenSocrates 2.0 개발 계획

**현재 상태: 개발 계획. 2.0의 구현이나 효과, 실제 호스트 연결을 증명하지 않습니다.** 이 문서 세트는 사용자와 논의한 새로운 방향을 반영하며, 이전 2.0 계획과 범위가 다를 때 이 문서 세트를 우선합니다. 기존 저장소의 개인정보·보안·출시·생성물 규칙을 변경하지 않습니다.

OpenSocrates 2.0은 사용자의 실제 작업 경험에 맞춰 추론 가이드를 발전시키고, 여러 앱의 대화 세션이 사용자 중심의 한 팀으로 일하도록 소통·맥락·위임을 연결하는 프로그램입니다. 설치 시 기존 48개 추론 가이드를 사용하며, 개인별 가이드가 적합하면 이를 선택·조합·재조립하고 없으면 적절한 기본 가이드를 활용합니다. 공통 가이드 생성 지침은 제품 버전업으로 발전하고, 사용자별 가이드는 각자의 경험에서 발전합니다.

첫 버전의 대상은 **ChatGPT 데스크톱 앱의 Chat·Work·Codex와 Claude 데스크톱 앱, macOS와 Windows**입니다. 각 모드·운영체제의 실제 연결 가능성은 별도로 확인해야 합니다. 에이전트 실행을 위한 별도 모델 API, Grok Bot·Cursor 신규 연결, 여러 컴퓨터 사이 동기화는 현재 범위가 아닙니다.

## 현재 계획: 읽는 순서

1. [제품 비전과 요구사항](VISION_2.0.ko.md): 사용자가 원하는 경험과 확정된 범위.
2. [시스템 구조와 데이터 흐름](SYSTEM_2.0.ko.md): 소통 계층, 실제 앱의 작업 세션, 가이드·맥락 전달과 개인별 학습.
3. [개발 로드맵과 인계](ROADMAP_2.0.ko.md): 작업 분해, 의존관계, 결정할 사항과 첫 시나리오.
4. [검증과 평가](VALIDATION_2.0.ko.md): 각 호스트·운영체제, 지속성·보안·품질·실제 사용 평가.
5. [English documentation](README.md).
6. [브라우저에서 읽는 통합 HTML 계획서](PLAN_2.0.ko.html). 이 파일은 네 개 한국어 계획서를 하나로 모은 스냅샷이다. 원본을 변경한 뒤 HTML을 별도로 갱신하고 내용과 링크를 다시 확인한다.
7. [데이터 흐름도 SVG](FLOW_2.0.ko.svg): HTML에도 포함되는 정적 요약 그림. 상세한 정본 흐름은 시스템 설계의 Mermaid 원문과 설명을 따른다.

HTML은 저장소 루트에서 아래 명령으로 네 한국어 원본을 다시 합쳐 갱신합니다. `markdown-it-py` 버전을 고정해 스냅샷의 재현성을 높이며, 갱신한 HTML의 내용과 링크를 검토합니다.

```sh
uv run --no-project --with 'markdown-it-py==4.2.0' python tools/render_v2_plan.py
```

목차의 제목·링크·중복 처리 검사는 브라우저를 열지 않고 다음 명령으로 실행한다. 실제 화면 배치와 키보드·스크린리더 동작은 별도 확인이 필요하다.

```sh
uv run --no-project --with 'markdown-it-py==4.2.0' python -m unittest tools/test_render_v2_plan.py
```

HTML의 각 장에 있는 세부 목차는 네 원문의 2·3단계 제목에서 자동 생성한다. 같은 제목은 다른 절을 추가하거나 앞의 숫자만 바꿔도 링크가 유지되지만, 제목 문구를 고치거나 같은 제목의 반복 순서를 바꾸면 이전 세부 링크가 달라질 수 있다.

시스템 설계의 첫 번째 Mermaid 흐름이 바뀌면 렌더러는 SVG의 원본 지문과 비교해 중단합니다. 변경된 흐름을 그림과 대체 텍스트에 반영하고 관계를 직접 검토한 뒤, 렌더러가 안내하는 지문으로 SVG의 `data-mermaid-sha256`을 갱신하고 다시 생성합니다. 지문 일치는 그림의 의미가 맞다는 자동 증명이 아닙니다.

기획 문서는 계획의 근거와 남은 결정을 기록합니다. 실제 모델의 내부 정렬, 개인화 품질 향상, 호스트 간 자동 전달은 아직 증명되지 않았습니다. 사용자가 대화하는 의뢰 세션은 상담과 조율을 맡고 실제 결과물 작업은 새 세션에서 수행합니다. 모든 에이전트 간 통신은 OpenSocrates 계층을 거칩니다.

## 이전 계획과 보존 자료

이전 2.0 자료는 역사적 근거와 당시의 검증 기록으로 보존하며, 현재 범위에 반하는 지시로 사용하지 않습니다. 특히 이전의 **Cursor 필수**와 **48개에 고정된 방법 선택**은 현재 선택을 대체하지 않습니다. [이전 마스터 플랜](MASTER_PLAN.md), [이전 백로그](IMPLEMENTATION_BACKLOG.md), [이전 제품·평가](PRODUCT_AND_EVALUATION.md), [이전 아키텍처](ARCHITECTURE_AND_MIGRATION.md), [이전 착수 지침](START_HERE.md), [이전 호스트 조사](HOSTS_AND_BOTS.md), [이전 평가 사례](EVALUATION_CASES.md)를 참고할 때 각 문서의 상태 표시를 따릅니다.

[v1.5.3 패키지·소스 인벤토리](RELEASE_BASELINE_1.5.3.md)는 과거 패키지와 소스의 부분 인벤토리이며 실제 호스트 전달·읽기·적용·품질의 증거가 아닙니다. 각 비교와 지원 주장은 그 주장에 해당하는 호스트·단계의 관찰에 근거합니다.
