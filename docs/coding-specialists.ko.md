# v1.5.0 후보의 코딩 전문 절차

아직 공개 배포하지 않은 이 후보에는 별도 버전의 정적 라이브러리
`coding-specialists/v0.1.1`이 포함됩니다. 사용자가 선택한 같은 모델이 중요한
소프트웨어 결정을 내리기 전에 돕습니다. 기존 일반 정본 48개는 그대로이며,
추가 모델·네이티브 의미 컴파일러·메모리 등록·모델 전환을 요구하지 않습니다.

| 미해결인 선택 | 관련 완전한 전문 절차 |
| --- | --- |
| 작업을 정의하는 입력·결과·실패·불변 조건은 무엇인가? | [계약과 불변 조건](../plugin-src/shared/coding-specialists/v0.1.1/contracts.ko.md) |
| 동작은 정해졌지만 순서·부분 효과·재시도·복구가 미해결이다 | [상태 전이와 실패](../plugin-src/shared/coding-specialists/v0.1.1/transitions.ko.md) |
| 규칙은 정해졌지만 기준·버전·변경 책임·공유 참조·파생 결과가 미해결이다 | [소유권과 파생 상태](../plugin-src/shared/coding-specialists/v0.1.1/ownership.ko.md) |

기존처럼 `opensocrates` 컨트롤러를 사용합니다.
[전문 라우터](../plugin-src/shared/coding-specialists/v0.1.1/router.ko.md)는 일반 방법을
먼저 거치지 않고 전문 절차를 주 절차로 선택할 수 있습니다. 기계적 작업, 이미
해결된 선택, 충분히 처리할 수 있는 일반적인 작업에는 추가 절차가 필요 없습니다.
별개의 미해결 필요가 있을 때만 보완합니다. 성능만의 문제에는 이 절차들을
불러오지 않고 기존 성능 안내를 사용할 수 있습니다.

설치된 파일 위치는 `skills/opensocrates/references/coding-specialists/v0.1.1/`입니다.
선택한 파일 전체를 읽고 근거·중단 조건을 유지합니다. 일반 판단에는 여전히
[일반 decision 경로](decision-points.ko.md)를 사용하며 빈 선택도 유효합니다.
판단이나 근거가 바뀌기 전까지 적용 가능한 내용을 재사용합니다. 절차는 작업을
돕기 위한 것이며 눈에 보이는 체크리스트를 항상 요구하지 않습니다.

정적 전문 절차는 EN·KO·중국어 간체(`zh-CN`)로 제공됩니다. 중국어 파일이 네이티브
`decision`, `assistance` 등 일반 요청 스키마를 확장하지는 않습니다. `csp-*`,
전문 파일 해시나 지원되지 않는 언어를 네이티브 정본 선택·읽음 신고에 전달하지
않습니다. 일반 방법이 필요하면 실제 지원되는 완전한 참조를 읽습니다. 전문 절차에는
네이티브 정본 활성화 영수증이 없으며 정본 접지 줄에 넣지 않습니다.

이 프롬프트들은 잠정 상태입니다. 파일 전달과 소스·패키지 검사는 가용성과 동일성을
확인할 뿐, 사고 능력 향상이나 보편적인 코딩 효과를 입증하지 않습니다.
[버전이 있는 개발 기록](v1.5.0/14-coding-specialists.md)은 직접 삽입 비교와 제품
경로의 실제 사용을 구분합니다. 과거 결과는 유지합니다. 직접 작성한 테스트의
통과나 방법 이름만으로 품질이 입증되지는 않습니다.
