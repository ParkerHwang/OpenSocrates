# OpenSocrates 1.4.0: Codex-only release

The maintainer changed the release scope on 2026-09-16 and authorized implementation,
validation, protected-branch merge, version tagging, GitHub Release publication,
and npm publication. This supersedes the previous PR #93 publication hold.

## Product contract

- Codex is the only supported host. Keep Apple-silicon macOS and Windows x64.
- Remove other host adapters, selectors, templates, installation choices, package
  generation, current support documentation, and release assets.
- Keep canonical reasoning methods, English/Korean parity, Codex hooks, explicit
  skills, local privacy controls, integrity checks, fail-open behavior, and safe
  transactional installation/rollback.
- Reject removed host names before any mutation. `--host all`, where retained
  for command compatibility, means Codex only.
- Existing non-Codex installations are not silently deleted. Explain how to use
  the version that installed them to uninstall them. Historical changelogs and
  evidence remain historical and cannot establish 1.4.0 support.

## Evidence boundaries

Native packaging and isolated install fixtures do not prove authenticated host
delivery. A used machine is not a clean-machine test. Windows ARM64, Linux native
packages, signing/SmartScreen, and Windows automatic updates are outside this
release unless separately implemented and validated. Do not publish credentials,
prompts, transcripts, account identifiers, or local machine paths as evidence.

## Current-machine baseline

Read-only inspection on 2026-09-16 found a Codex 1.0.0 managed package and cache,
no default desired-state manifest, and no Claude managed package or cache.
Codex authentication is available. This differs from the historical 1.3.1
baseline in the former PR handoff. Do not claim or manufacture a 1.3.1-to-1.4.0
acceptance run on this machine. Validate the actual installed baseline through
the ordinary transactional installer, preserving an accurate version transition
and any unavailable manual or separate-clean-machine evidence.
