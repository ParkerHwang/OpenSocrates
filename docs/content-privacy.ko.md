# OpenSocrates 콘텐츠 전용 패키지 개인정보 안내

[English](content-privacy.md) · [에이전트 안내](agent-discovery.ko.md)

최근 수정: 2026년 10월 13일.

적용 범위는 릴리스된 v1.5.1 Claude 계정용 스킬과 같은 스킬 파일을 담아 별도로 준비한 미공개 OpenAI 래퍼입니다. 네이티브 실행형 통합은 이
안내의 대상이 아니며, 해당 프로필은 [보안
정책](https://github.com/ParkerHwang/OpenSocrates/blob/5a6a7fa2897dd42772c4503a1301770e48bd1f29/SECURITY.md)을
참고하세요. OpenAI 래퍼는 디렉터리에 제출되거나 승인되지 않았습니다.

콘텐츠 전용 패키지는 추론 지침과 참조 파일로 구성됩니다. 훅, 실행 런타임, 자격증명 접근, 텔레메트리, 개발자가 운영하는 서비스가 없습니다. 패키지는
프롬프트, 업로드한 파일, 대화 기록 또는 계정 자격증명을 개발자에게 전송하지 않습니다. 패키지를 통해 이러한 작업 내용을 수신하거나 보관하는 개발자 서비스가
없으므로, 해당 내용의 개발자 측 수신 대상이나 보관 기간도 없습니다.

사용하는 AI 호스트는 자체 개인정보 처리방침, 권한 및 보관 설정에 따라 사용자가 제공한 내용을 처리합니다. OpenSocrates는 그 정책을 대체하지
않습니다. 호스트에서 제공하는 스킬·플러그인 제어 기능으로 패키지를 비활성화하거나 제거하고, 대화 제어 기능으로 저장된 대화를 관리할 수 있습니다. 패키지를
제거해도 호스트의 대화 기록은 삭제되지 않습니다.

자발적으로 [공개 GitHub 지원 이슈](https://github.com/ParkerHwang/OpenSocrates/issues)를 작성하면, 포함한
본문과 첨부 파일 및 GitHub 계정 식별정보가 유지관리자와 일반에 공개됩니다. 유지관리자는 지원 요청에 대응하기 위해 이 정보를 사용할 수 있습니다.
저장·보관 및 제공되는 수정·삭제 기능은 GitHub의 정책과 제어 기능을 따르며, 이 안내에서 별도의 고정 삭제 일정을 약속하지 않습니다. 공개 이슈에
자격증명, 비공개 프롬프트, 대화 기록 또는 기밀 파일을 올리지 마세요. 취약점은 [보안
정책](https://github.com/ParkerHwang/OpenSocrates/blob/5a6a7fa2897dd42772c4503a1301770e48bd1f29/SECURITY.md)에
따라 [GitHub 비공개 보고
경로](https://github.com/ParkerHwang/OpenSocrates/security/advisories/new)로 신고하세요.
