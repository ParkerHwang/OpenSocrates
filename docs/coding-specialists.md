# Coding specialists in the v1.5.0 candidate

This unpublished candidate includes a separately versioned static library,
`coding-specialists/v0.1.1`. It supports the chosen model before a consequential
software decision. The 48 complete general methods remain unchanged; no additional
model, native semantic compiler, memory enrollment or model switch is required.

| Unresolved choice | Relevant complete procedure |
| --- | --- |
| Which inputs, results, failures and invariants define the operation? | [Contracts and invariants](../plugin-src/shared/coding-specialists/v0.1.1/contracts.en.md) |
| Behavior is known, but ordering, partial effects, retries or recovery remain unresolved | [State transitions and failure](../plugin-src/shared/coding-specialists/v0.1.1/transitions.en.md) |
| The rule is known, but authority, version, mutation responsibility, aliases or projections remain unresolved | [Ownership and derived state](../plugin-src/shared/coding-specialists/v0.1.1/ownership.en.md) |

Use the `opensocrates` controller normally. Its [specialist router](../plugin-src/shared/coding-specialists/v0.1.1/router.en.md)
can choose a specialist as the primary procedure, without a general-method pass
first. Mechanical/resolved or adequately handled ordinary work needs no extra
procedure. Use a complement only for a distinct unresolved need. Performance-only
work can use the existing performance guidance without loading these procedures.

The installed files are at `skills/opensocrates/references/coding-specialists/v0.1.1/`.
Read the complete selected file; preserve its evidence and stop boundaries.
General judgments still use the [general decision path](decision-points.md),
including valid empty selection. Reuse applicable content until the decision or
evidence changes. The procedures guide the work, not a required visible checklist.

EN, KO and Simplified Chinese (`zh-CN`) versions are included for static specialist
delivery. Chinese does not extend the native `decision`, `assistance` or other
general request schemas. Do not pass `csp-*`, specialist file hashes or unsupported
locales to native canonical selection/acknowledgment. A needed general method must
be read in an actually supported complete reference. Specialist use has no native
canonical activation receipt and does not belong in the canonical grounding line.

These prompts are provisional. File delivery and source/package checks establish
availability and identity, not cognitive improvement or universal coding benefit.
The [versioned development record](v1.5.0/14-coding-specialists.md) separates direct
prompt comparisons from integrated route behavior. Historical outcomes remain
unchanged. Neither a passing self-authored test nor a method name proves quality.

See [한국어](coding-specialists.ko.md) and the
[Chinese router](../plugin-src/shared/coding-specialists/v0.1.1/router.zh-CN.md).
