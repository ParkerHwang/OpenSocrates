# OpenSocrates v1.3.1 release

The maintainer requested v1.3.1 publication, npm publication, current README and
official homepage updates, and cleanup of completed release branches on 2026-09-09.

## Scope and acceptance

This patch repairs bounded one-shot JSON parsing, adds the real packaged-example
regression, requires GitHub release immutability, and repairs concurrent lifecycle
blocked-receipt publication. The original 48 methods and 96 EN/KO procedure bodies,
Response Policy, host delivery models and eligibility rules are unchanged.

Release acceptance requires the complete source suite, native package build and
packaged-example selection, five required PR checks, an exact merged tag, immutable
GitHub publication, public-byte verification and matching npm publication. README,
advanced installation guides and the existing public Sites homepage must point to
1.3.1. Completed branches may be removed only after merge; unfinished or dirty
worktrees remain preserved.

The previous [v1.3.0 behavioral evidence](v1.3.0-recovery/PROGRESS.md) remains
historical. This patch adds no new live host or answer-quality claim. Existing
unvalidated GUI, separate-Mac installation, signing/notarization and Chat cloud
activation are disclosed support limits, not assertions made by this patch.
`applied: unverified` does not prevent completion of the user's requested artifact.

## Verification record

Current source, checks and publication receipts are maintained in
[PR #92](https://github.com/ParkerHwang/OpenSocrates/pull/92). GitHub's release
workflow independently rebuilds the tag and compares all published assets against
its validated local files. Its immutable-release guard must remain enabled.

The release artifact remains native to Apple-silicon macOS. The official site is
[OpenSocrates](https://opensocrates.parker-j-hwang.chatgpt.site). Repository Pages
was not configured at preflight; the GitHub README is the repository entry point.
