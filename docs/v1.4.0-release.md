# OpenSocrates v1.4.0 — Codex only

The maintainer revised v1.4.0 on 2026-09-16 to support Codex exclusively on
Apple-silicon macOS and Windows x64. Other host integrations and release assets
were removed. The 48 methods, English/Korean procedures, private runtime state,
bounded hooks, package integrity and transactional installation remain.

The [execution plan](v1.4.0-release-plan.md) and
[PR #93](https://github.com/ParkerHwang/OpenSocrates/pull/93) record release
progress. The [tagged release](https://github.com/ParkerHwang/OpenSocrates/releases/tag/v1.4.0)
is the publication authority once published; candidate validation alone is not
publication evidence.

## Candidate evidence, 2026-09-16

Verified source: `155cdacec63828a662c040dade66f3acac46987d`.

- Complete local source checks, generated contracts, content/locale validation,
  1,854 adjudication checks, 83 validator scenarios and 30 coherent mutations
  passed on Apple-silicon macOS.
- Node installer, lifecycle, recovery, trust, privacy and release-gate tests:
  248/248 passed, plus packed npx smoke.
- Native `make release-check` passed on clean committed source. SessionStart
  p95 was 16.657 ms, and compact-summary p95 was 115.091 ms, each over 20 samples.
- The macOS archive verified 296 inventoried files. Its package manifest SHA-256
  was `adba6252d639a0102d3862ac3b89e2c3e8cba2fe09b6e9a6a8f5872893286c64`.
- The real managed Codex installation updated from 1.0.0 to 1.4.0 using the packed
  candidate. This was an ordinary transactional update on a used Mac, not a
  purge, 1.3.1 baseline cycle or separate clean-machine test.
- An authenticated ephemeral Codex turn, a synthetic shell command and explicit
  compaction completed. Exact installed-package notifications showed six hooks:
  SessionStart (22 ms), UserPromptSubmit (125 ms, with OpenSocrates context),
  PreToolUse (121 ms), PostToolUse (120 ms), Stop (151 ms), PreCompact (119 ms).
  Seven hooks were already trusted; the probe enabled them only for its
  invocation. Hook inventory had no warnings or errors. No hook-trust bypass
  was used, and persistent user preferences were preserved. SessionEnd was not
  observed after thread unsubscription and is not claimed validated here.
- [CI run 35049365576](https://github.com/ParkerHwang/OpenSocrates/actions/runs/35049365576)
  passed Windows native build/package/lifecycle checks, Windows npm checks,
  Python quality and the Linux installer suite. The overall run failed because
  its event snapshot contained two incorrect PR-description field names; that
  description was fixed. This run is not a full-green CI claim.

The bounded live receipt is in
[codex-live-v1.4.0.json](evidence/codex-live-v1.4.0.json). It contains categories,
timings and package identity, without prompts, replies, credentials, account
identifiers, thread identifiers or local paths. Automatic hook delivery does not
prove complete method reads, correct application or answer-quality improvement.
First-time trust review and recorded manual acceptance were not performed.

See [Windows support](windows-support.md) and the
[Korean guide](windows-support.ko.md). Windows automatic updates, Windows 10/ARM64,
macOS Intel, Linux native packages, signing/SmartScreen and a separate
clean-machine acceptance are not claimed validated. Earlier multi-host records
remain historical and do not establish current support.

## 한국어

1.4.0은 Codex만 지원하며 Apple silicon macOS와 Windows x64용 패키지를 제공합니다.
다른 호스트의 통합과 배포 파일을 제거했고, 48개 방법·한영 절차·비공개 런타임
상태·실행 시간이 제한된 훅·파일 무결성 검증·안전한 설치와 복구는 유지합니다.

위 커밋에서 로컬 전체 검사, 248개 Node 테스트, macOS 네이티브 릴리스 검사를
통과했습니다. 실제 사용 중인 Mac에서는 Codex 1.0.0을 1.4.0으로 업데이트하고,
인증된 Codex에서 도구 실행과 대화 압축을 수행해 여섯 훅의 자동 실행 및
OpenSocrates 문맥 전달을 확인했습니다. 기존에 신뢰된 훅을 검사 프로세스에서만
켰으며 사용자 설정은 유지했습니다. SessionEnd 알림은 관찰하지 못했습니다.
Windows 빌드·패키지·수명주기 검사도 통과했지만 해당 CI 전체 실행은 PR 설명
필드 이름 오류로 실패했습니다. 수정 후 최종 CI는 PR에서 별도로 확인합니다.

이 결과는 최초 훅 승인, 1.3.1 제거·재설치, 별도 새 기기 인수검증, 전체 참조 읽기,
방법 적용, 답변 품질 향상을 증명하지 않습니다. 기록에는 원문 대화·인증 정보·계정
식별자·로컬 경로를 포함하지 않습니다. 공개 배포 여부는 태그 릴리스를 기준으로
확인하며, 위에 명시한 미검증 플랫폼과 서명·자동 업데이트의 한계를 유지합니다.
