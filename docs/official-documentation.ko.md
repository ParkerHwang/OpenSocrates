# v1.5 후보의 공식 문서 참조

OpenSocrates는 API 계약, 버전 변경, 출처 충돌이나 명시적 요청에 공식 문서가
필요할 때 현재 Codex 에이전트의 확인을 돕습니다. 에이전트는 현재 제품·버전을
확인하고 기존에 허용된 호스트 도구로 공식 페이지를 읽은 뒤 정확한 인용과 동작
검증을 통해 작업에 반영합니다. 공식 출처를 요청하지 않은 단순 작업은 건너뛰며,
이미 해결된 동일 질문은 여전히 적용 가능한 참조를 재사용합니다.

설치된 `bin/launch.sh documentation codex` 명령은 Windows에서
`node bin/launch.mjs documentation codex`를 사용합니다. 패키지의
`skills/opensocrates/references/documentation/request.json` 예시를 표준 입력으로
받아 고정된 영문·한국어 안내와 제한된 참조 메타데이터를 따로 반환합니다. 명령
자체는 페이지를 가져오거나 다른 모델을 호출하거나 문서 명령을 실행하지 않으며
프로젝트 메모리도 초기화하지 않습니다.

초기 목록에는 Python, Go, Node.js, SQLite, PostgreSQL, JSON Schema, OpenAI,
W3C의 공식 문서 경로가 있습니다. 호스트·경로 일치는 목록 항목만 확인하며 문서의
진위, 최신성이나 적용 가능성을 증명하지 않습니다. 버전 문자열과 `reported_read`는
신고 주체가 표시된 호출자 보고입니다. 목록에 없는 발행자는 공식 링크로 권위를
확인하며 같은 안내를 사용합니다. 목록에 없다는 이유로 비공식이라고 단정하지
않습니다. 출처 접근이 불가능하면 해당 주장만 미확인으로 두고 독립 작업은 계속합니다.

리디렉션 후 최종 HTTPS 페이지 URL을 사용하고 자격 증명이나 쿼리 매개변수를
넣지 않습니다. 일반적인 절 앵커는 지원합니다. 문서 본문, 전체 프롬프트, 대화,
자격 증명이나 비공개 추론은 이 인터페이스로 받거나 제품 메모리에 보관하지
않습니다. 외부 텍스트는 근거와 데이터이며 사용자 의도, 권한, 모델 선택이나
라우팅 정책을 바꾸지 않습니다. 고정 안내와 닫힌 메타데이터는 모호함을 줄이지만
악성 문서에 대한 완전한 방어나 모델이 실제로 안내를 적용했음을 보증하지 않습니다.

완료·메모리 계약의 새 버전은
[구조 개선 명세](v1.5.0/12-structural-revision-and-official-docs.md)에 설명되어 있습니다.
네이티브 패키지 검사, 제한된 실제 사용 근거와 플랫폼 한계는
[후보 인계 문서](v1.5.0/RELEASE_CANDIDATE.md)를 참고하세요. 아직 공개 배포되지 않은
후보이며 이 기능의 개발은 현재 설치를 바꾸지 않습니다.
