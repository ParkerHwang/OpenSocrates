# 사무업무 사례 팩 v1

로컬 평가 도구에서 사용할 한국어 가상 사무 과제 8개를 새로 작성했습니다.
자료 속 조직·인물·행사·수치·메시지는 모두 허구입니다. 실제 수신자, 계정,
비공개 문서, 외부 자료나 실행할 업무는 없습니다. `public_synthetic: true`는
작성된 자료의 성격이며, 사용자가 자기 업무를 공정하게 대표한다고 승인했다는
뜻은 아닙니다. 실행 전 확인 화면에서 사용자가 이를 승인해야 합니다.

비교하려는 것은 상황에 맞게 답변 전체가 쓸모 있는지입니다. 전달하려는 뜻,
읽는 사람, 관계, 선택한 내용, 참조, 구성과 다음 업무가 함께 작용합니다.
문법이나 문장 다듬기만을 효과 전체로 보거나, 선호 문체와 OpenSocrates의 승리를
미리 정하지 않습니다.

## 사례 구성

| ID | 단계 | 상황 |
| --- | --- | --- |
| `cal-room-change` | 절차 확인 | 시간은 그대로인 설명회의 장소 변경을 동료에게 알립니다. |
| `cal-project-status` | 절차 확인 | 회의에 없던 팀장에게 검토와 배포를 구분해 진행 상황을 전합니다. |
| `dis-simple-notice` | 탐색 | 프린터 상태를 한 줄로 알립니다. 의도적으로 단순한 대조 사례입니다. |
| `dis-conflicting-updates` | 탐색 | 옛 계획, 완성된 파일, 새로 확정된 매장별 배포를 종합합니다. |
| `dis-relational-decline` | 탐색 | 기존 관계와 작성자의 한계를 유지하면서 무료 협업 요청을 거절합니다. |
| `dis-send-priority` | 탐색 | 미완성 개발 정보에서 지금 보낼 답장과 팀장 확인 요청을 정합니다. |
| `confirm-archive-intake` | 확인 | 기증자의 기한과 조건부 접수 가능 시간을 함께 다루는 새 문의입니다. |
| `confirm-expo-scope` | 확인 | 확정된 시연 범위와 미정인 제품 일정을 구분해 고객 초대 업무를 돕습니다. |

절차 확인 2개는 설치, 수집, 평가 진행이 되는지 보는 용도입니다. 효과를
입증하거나 품질 기준을 확정하는 근거가 아닙니다. 탐색 4개는 다른 종류의 업무를
제공하며, 추가 분석이 오히려 부담일 수 있는 단순 사례도 포함합니다. 확인 2개는
별도의 조직과 사실관계를 담았습니다. 평가자가 내용을 미리 읽거나 기준을
조정하는 데 쓰지 않았을 때만 새 확인 사례입니다. 이 목록만 읽으면 세부 사실은
드러나지 않지만 해당 자료를 읽으면 알게 됩니다. 소스 공개와 접근 차단은 다릅니다.

## 팩 계약

`pack.json`은 `opensocrates.office-pack/1` 형식이며, 팩 ID는
`office-work-v1`, 버전은 `1.0.0`입니다. 영어·한국어로 된 고정 B 지시 4문장,
사례 8개, 평가자에게만 공개할 사실 점검을 담습니다. 각 사례는 나열한 상대 경로의
Markdown 자료만 참조합니다. 실행 환경에는 해당 자료와 과제·결과물 범위만
복사해야 합니다. 이 안내, 절차, 다른 사례, `pack.json`, 조건 기록이나 평가자
점검은 복사하면 안 됩니다. 공통 결과 저장 안내는 실행 도구가 별도로 붙입니다.
호스트에는 해당 실행의 전용 폴더만 연결합니다. 폴더 분리 자체가 운영체제의
접근 차단을 보장하지는 않습니다.

세 조건의 과제, 자료, 추가 질문에 대한 고정 답변과 결과물 범위는 같습니다.
B는 모든 사례에 같은 짧은 지시를 추가합니다. C는 고정 버전의 지원된 콘텐츠
설치 방식을 사용하며, 사례 안에서 특정 방법을 고르라고 하지 않습니다. B 지시의
영어·한국어는 뜻을 맞췄습니다. 초기 과제와 자료는 한국어이며, 다국어 결과를
검증했다는 주장은 하지 않습니다.

모델 실행, 사용자 선호, 사람 평가나 효과 측정 결과는 포함하지 않습니다.
이 사례들은 도구 설계 후 작성했으며 특정 조건에서 좋은 답이 나왔기 때문에
고른 것이 아닙니다. 과제·B 지시·사실 점검을 바꾸면 버전과 해시를 바꾸고 새
연구 식별자로 고정해야 합니다. 결과를 좋게 만들려고 진행 중인 연구의 고정
입력을 바꾸면 안 됩니다.
