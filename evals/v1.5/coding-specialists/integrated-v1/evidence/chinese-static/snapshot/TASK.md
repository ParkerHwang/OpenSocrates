# 文档标签索引的所有权

请用已安装的 OpenSocrates 在相关的编程决策上提供支持，然后完成这个一次性项目。请使用简体中文交流。规则已经确定，当前问题是对象的所有权与共享引用，不需要重新选择业务规则。

`TagIndex.put(document, metadata)` 接受文档名和 JSON 兼容的嵌套字典，替换该文档的数据。调用者之后修改传入字典或其中的列表，不得改变索引。`summary()` 返回当前全部文档的一个独立结果；调用者修改返回结果不能改变索引，后来对索引的修改也不能改变已经返回的结果。保留嵌套值、列表顺序和重复项，不把标签擅自转换成集合。此任务不涉及并发、远程数据或新增持久化机制。

保留 `put`、`summary` 和 `render_count` 的公开入口。修复实现，添加必要的行为测试，运行 `python -m unittest discover -s tests -v`。没有新依赖、网络操作或额外审批需要。中国语种只需要使用实际存在的静态专业文件；不要假定原生通用 API 支持 `zh-CN`，也不要把专业 ID 当成通用规范方法 ID。
