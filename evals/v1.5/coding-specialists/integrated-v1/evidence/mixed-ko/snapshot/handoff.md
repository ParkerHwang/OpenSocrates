# 인계

## 로컬 처리 완료

- `apply_result(state, generation, value)`는 전달된 generation이 `state["generation"]`과 같을 때만 `state["result"]`를 갱신하고 `True`를 반환합니다.
- 과거 또는 미래 generation은 입력 딕셔너리를 바꾸지 않고 `False`를 반환합니다.
- generation은 이 함수에서 증가시키지 않습니다. 입력 딕셔너리 자체를 갱신하는 계약도 유지했습니다.
- 확인 명령: `python -m unittest discover -s tests -v`
- 실행 결과: 4개 테스트 모두 통과 (`OK`, exit code 0).

## 외부 공급자 재시도 정책: 미확인

공급자의 멱등성 지원, 결과 확인 API, 중복 발행을 허용할 수 있는 조건이 제공되지 않았습니다. 외부 접근도 수행하지 않았습니다. 따라서 재시도 허용 여부와 시간 초과 후의 처리는 아직 결정할 수 없습니다. 시간 초과만으로 작업이 롤백됐다고 간주하지 않습니다.

정책을 정하기 전에 공급자 문서 또는 담당자에게 다음을 확인해야 합니다.

1. 멱등성 지원 여부와 적용 범위, 키의 유효 기간, 같은 키로 다시 보낸 요청의 동작.
2. 발행 결과를 조회할 API의 유무, 조회에 필요한 식별자, 진행 중·성공·실패·확인 불가 결과의 의미와 반영 지연.
3. 중복 발행을 허용할 수 있는 업무 조건과 중복 시 영향.

이 조건이 확인되면 결과가 불명확한 요청을 어떻게 조회할지, 어떤 경우에 같은 작업을 다시 보낼지 공급자 계약에 맞춰 결정합니다. 그 전에는 이 인계 문서를 재시도 허용 또는 롤백 확인으로 해석하지 마세요.
