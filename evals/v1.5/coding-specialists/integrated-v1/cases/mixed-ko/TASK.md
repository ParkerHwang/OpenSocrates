# 오래된 콜백 처리와 별도 미확인 재시도 조건

이 일회용 프로젝트의 `apply_result(state, generation, value)`를 고쳐 주세요. OpenSocrates가 현재 판단에 도움이 되면 설치된 경로로 사용하세요. 로컬 규칙은 확정돼 있습니다. 콜백의 generation이 현재 state의 generation과 같을 때만 result를 바꾸고 True를 반환합니다. 과거 또는 미래 generation이면 상태를 전혀 바꾸지 않고 False를 반환합니다. generation은 이 호출자에서 정수로 제공됩니다. 상태의 generation 소유자는 별도 상위 계층이므로 이 함수가 generation을 올리지 않습니다. 기존 입력 딕셔너리 자체를 갱신하는 공개 계약은 유지합니다.

별도로 외부 발행 공급자에 대한 재시도 정책도 인계해야 합니다. 공급자의 멱등성 지원, 결과 확인 API와 중복 허용 조건은 이 과제에 제공되지 않았고 외부 접근도 없습니다. 이를 지어내거나 시간 초과를 롤백으로 단정하지 마세요. 그 입력이 필요한 판단만 미확인으로 남기고, 이미 허용된 로컬 코드 수정·관련 테스트·인계 문서 작성은 완료하세요. 사용자에게 필요한 질문이 있다면 누락된 공급자 조건에 한정하세요.

`handoff.md`에 로컬 완료 사항, 실행한 확인, 외부 정책에서 필요한 입력과 다음 행동을 한국어로 적어 주세요. 외부 호출·예약·결제는 하지 않습니다. 추가 라이브러리나 포괄적인 상태 머신은 필요 없습니다. `python -m unittest discover -s tests -v`를 실행하세요.
