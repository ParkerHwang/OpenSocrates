# Integrated specialist delivery pilot v1

This is a separate five-case product-route check, not another content-effect
comparison. Exact package bytes and task/runner/checker/tuple identities must be
frozen in manifest.json before calls. Use the same gpt-6-luna/max client/account
tuple as the direct-delivery pilot. No model wall-clock cutoff or helper subagents.

Each cell installs the candidate ZIP into its own disposable Codex profile. Hooks,
native memory/import, apps, remote plugins and multi-agent support are disabled.
The task gives a normal explicit cue to use the installed OpenSocrates controller
when relevant, and its actual installed controller path. It does not supply the
specialist body or tell the model which specialist to choose. This tests an
explicitly invoked installed controller route with hooks off, not universal
automatic discovery or native hook activation. Normal hook composition/package
checks and any live hook evidence remain separately attributed.

The cases cover English contract support, Korean mechanical non-intervention,
English general reasoning, Korean independent work beside a missing external
guarantee, and Simplified Chinese static specialist delivery. Read actual generated
code/data and public messages; run protected existing tests and independent checks
on copies of locked artifacts. Inspect observed complete-file delivery, native
operations/rejections, unnecessary dual loading, final claims and relevant language
behavior separately. A successful program is not proof that the prompt was applied.

The Chinese case establishes only the observed static file interaction, not full
native Chinese API support or empirically equivalent behavior across all languages.
Human review is unavailable. Missing usage stays null. All setup failures, calls,
failed actions and skipped cells count. No automatic outcome retries or stronger
model repairs. Live Windows Codex remains unavailable; native Windows CI is separate.

`plan_objective_measure`: show a usable specialist-primary route without breaking
mechanical/general/mixed work or claiming unsupported native registration.

`do_scope`: five disposable installed-package calls with exact tuple and owned
synthetic projects; no active installation or global settings change.

`check_rule`: pre-call freeze, immutable output snapshots, artifact/state checks,
complete public-message review and attributed route observations.

`act_standardize_decision`: pending observed results. Delivery failures remain
failures and do not become quality claims; keep the library provisional.
