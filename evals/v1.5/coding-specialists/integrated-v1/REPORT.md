application. The general method's rejection is preserved; successful artifact
completion must not relabel it as successful application. The selector is driven

not established; it is recorded as a non-application, not an applied-method win.

No supplied protected input or any of the nineteen bound package members changed.

removed. No helper agents, model switching, stronger-model repair, raw reasoning
capture or generation wall-clock cutoff was used. One failed tool action is a
no-match AGENTS search in the mixed case; it was retained and did not block work.
The Chinese case also reruns its already-passing suite without an intervening
source edit and repeats a diff check. That redundant work is retained in the action
and usage totals; artifact success is not a claim of optimal stopping or efficiency.

## Completion and limits

`act_standardize_decision`: the bounded installed route is usable: specialist-primary
EN and static Chinese delivery, Korean non-intervention/scoped continuation, and
general retrieval with explicit non-application are observed. Keep the library
provisional and optional for unresolved decisions; retain ordinary/current-guide
fallback and unpromoted model profiles. No further unchanged model calls are needed.

Korean collaboration is observed, and all Korean specialist bytes were checked and
reviewed for parity; this pilot does not isolate Korean specialist efficacy. Chinese
is static specialist content, not a translated general catalog or native request
locale. Normal hook activation, live Windows Codex, independent human language
review and account-side memory isolation remain unavailable/unproven as applicable.
Source/native/hosted platform checks are separate from those missing live cells.

Public synthetic receipts and code are in `evidence/`; [export-map.json](export-map.json)
binds 72 exported files to immutable originals. Only five interpreter paths in
TOOLING.md environment notes are redacted. Business source and original score/snapshot
