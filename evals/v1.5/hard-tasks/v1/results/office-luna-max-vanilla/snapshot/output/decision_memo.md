# 지역 직원 교육 4회차 개설 권고

**수신:** 운영책임자  
**작성 기준일:** 2026-09-27  
**결정 요청:** CEDAR 공급사 선택 서명 1건  
**상태:** 서명 대기 중 (`supplier_selection_pending`)

## 권고

최종 승인 견적에 따라 **CEDAR**를 선택하고, 승인된 시설 세션 **S2(10월 6일), S3(10월 8일), S5(10월 12일), S6(10월 13일)**를 묶은 4회 운영안을 결재해 주십시오. 이는 계획 권고이며 선택 서명이나 예약·발주·지급이 완료된 것은 아닙니다. 총 4회 요건과 승인 기간(10월 5–13일)을 만족하고, 10월 9일 휴무일과 제안 상태인 S4는 사용하지 않습니다(OPS-APPROVAL-0926; FACILITY-0926의 S2/S3/S5/S6, S4; SUPPLIER-EMAIL-0926).

| 항목 | 권고 계획 |
|---|---:|
| 공급사 / 승인 단가 | CEDAR / 기본 240,000원 + 배정자 1인당 7,000원 (SUPPLIER-TERMS-FINAL-0926) |
| 회의실 비용 | 260,000원: S2 80,000 + S3 60,000 + S5 70,000 + S6 50,000원 (FACILITY-0926) |
| 대사된 기존 미지급 잔액 | 787,600원 — 36개 송장 잔액 합계 |
| 승인 총현금 한도 / 교육 신규 지출 한도 | 1,752,600원 / 965,000원 |
| 신규 교육비 | 962,000원 = 기본 240,000 + 66명 × 7,000 + 방 260,000원 |
| 신규비 집행 후 한도 여유 | **3,000원**; 기존 미지급 787,600원은 별도 유보 |

현금 산식은 `총현금 한도 1,752,600원 − 기존 송장 잔액 787,600원 = 신규 지출 한도 965,000원`입니다(OPS-APPROVAL-0926의 `total_cash_cap_krw`, `cash_rule`). 제안된 추가 70,000원은 승인되지 않았으므로 상한이나 여유에 더하지 않았습니다(OPS-APPROVAL-0926의 `pending_extra_budget_krw`). 세금 포함 정수 KRW이며 추가 반올림은 없습니다(RULES-0927).

## 대사 결과와 근거

물리적 송장·크레딧·지급 **101행**을 각각 보존해 `records.csv`에 기록했고, INV01–INV36 **36개 논리 송장**의 잔액을 `balances.csv`에 정리했습니다. 이 결과의 합계는 송장 총액 881,200원 − 유효 크레딧 6,600원 − 유효 지급 87,000원 = 기존 미지급 787,600원입니다. 최신 posted 대표 행만 금액에 반영하고 중복·이전 revision·draft·void·reversed 행은 0원 인식으로 남겼습니다(RULES-0927 §§3–4).

대표 근거 예: INV01은 I-B01 대신 최신 I-R01(12,900원)을 적용했고, CR01은 C-B01 대신 C-R01(750원)을 적용했습니다. PAY16의 최신 대표 P-R16은 `reversed`라 유효 지급 0원이며, 이전 P-B16은 superseded입니다. 재전송 P-D01은 P-B01과 같은 거래의 duplicate로 금액을 중복 합산하지 않았습니다. 금액 0인 posted 대표도 제거하지 않아 C-B10, P-Z19가 active 0원 행으로 남고, INV33은 최신 I-V33 void 대표를 보존해 총액 0원으로 처리했습니다(입력 04_invoices.csv·05_credits.csv·06_payments.csv의 해당 row_id; 전체 판정은 대사기록·송장잔액 시트 참조).

## 명단·배정·접근성

승인 HR 변경만 적용한 최종 활동 명단은 **필수 60명 전원 + 선택 12명**입니다. H02로 P010은 선택에서 필수로, H03으로 P061은 필수에서 선택으로 바뀌었고, H04로 이전 철회 상태였던 P072가 복귀했습니다. H01/H05는 P005와 P064의 접근 필요를 true로 바꿨습니다. H11–H12는 pending이므로 P063 승격과 P005 접근성 해제는 반영하지 않았습니다(03_hr_changes.csv H01–H12; 기본 상태는 01_roster.csv R005/R010/R061/R063/R072).

최종 배정은 **66명(필수 60명, 선택 6명)**이며 각 참석자는 허용 세션 중 하나에 한 번만 배정했습니다. 배정은 S2 18명, S3 15명, S5 18명, S6 15명으로 각 세션을 실제 사용하고 정원 안에 둡니다. S2와 S5만 접근 가능(true)이므로 접근 필요 인원은 그 두 세션에 배정했습니다. S3 방 정원 16명이 공급사 한 회차 정원 18명보다 작아 실효 정원은 16명이고, S3와 S6은 접근 불가입니다(FACILITY-0926, S2/S3/S5/S6; SUPPLIER-TERMS-FINAL-0926의 `capacity_per_session`).

대기자는 **P064, P066, P069, P070, P071, P072**입니다. P064는 H05로 접근 필요가 승인됐고 허용 세션이 S3/S6뿐인데 두 세션 모두 접근 불가라 배정 가능한 자리가 없습니다(02_availability.csv A064; 03_hr_changes.csv H05). 나머지 다섯 명은 선택 인원 수를 여섯 명으로 제한하는 현금 한도 때문에 대기입니다. 특히 P066/P070–P072는 세션별 여유 좌석이 있어도 CEDAR의 1인당 7,000원을 추가하면 총 신규비가 한도를 넘습니다(02_availability.csv A066/A069/A070/A071/A072; OPS-APPROVAL-0926). 최종 active 선택 인원 12명 중 6명을 배정해 가능한 선택 참석 수를 최대화했습니다. 60명 필수 참석과 네 세션 방값·공급사 기본료를 반영한 뒤 배정 가능한 인원은 66명입니다. 일곱 번째 선택 인원까지 포함하면 CEDAR 신규비는 969,000원으로 965,000원 한도를 4,000원 초과합니다. 지역별 쿼터나 개인 우선순위는 적용하지 않았습니다(RULES-0927 §§2,5–7).

## 대안과 선택 이유

필수 인원 조건상 S3가 필요합니다(P025는 승인된 H07에 따라 S3만 가능); S5는 P020의 H06 변경, S6은 P060의 H09 변경 때문에 필요합니다. 네 번째 세션으로 S1은 대체가 될 수 없고 S2가 필수입니다. P001–P015 중 12명과 P031–P045 중 13명은 허용 세션이 S2/S5뿐이며, P020은 S5만 가능합니다. S5의 실효 정원은 18명이므로 이 26명의 필수 인원 전원 배정에는 S2가 필요합니다(02_availability.csv A001–A015/A031–A045; 03_hr_changes.csv H06–H09; FACILITY-0926). S2 방값(80,000원)은 S1(90,000원)보다 10,000원 낮기도 합니다. 선택한 세션 조합에서 CEDAR로 66명(필수 60 + 선택 6)을 962,000원에 배정해 3,000원을 남깁니다. 일곱 번째 선택 인원은 잔액보다 4,000원 많은 비용을 요구합니다. P064는 실제 A064에서 S1이 허용되지 않고 S3/S6만 가능하므로 접근 가능한 S1로 바꿔도 해당 인원을 배정할 수 없습니다(RULES-0927 §§5–7; 02_availability.csv A064).

동일한 66명과 S2/S3/S5/S6을 기준으로 승인 공급사를 비교하면 CEDAR는 240,000 + 66×7,000 + 260,000 = **962,000원**, ORCHID는 285,000 + 66×6,500 + 260,000 = 974,000원, LYRA는 200,000 + 66×8,000 + 260,000 = 988,000원입니다. CEDAR가 비용상 ORCHID보다 12,000원, LYRA보다 26,000원 낮으며 66명을 한도 안에 수용하는 유일한 승인안입니다. 같은 한도에서 ORCHID의 최대 배정은 64명(신규비 961,000원, 선택 4명), LYRA는 63명(964,000원, 선택 3명)입니다. 기본료만 보면 LYRA가 낮지만 인당료가 높아 최대 가능한 참석 수가 가장 적습니다(SUPPLIER-TERMS-FINAL-0926). CEDAR-PILOT은 더 낮은 제안 가격이더라도 승인 상태가 pending이므로 비교·선정 대상에서 제외했습니다(08_supplier_terms.json; SUPPLIER-EMAIL-0926).

S4는 10월 9일의 40,000원 저가안이지만 `proposed`이며 회사 휴무일이므로 승인 4회 계획에 넣을 수 없습니다(07_session_options.csv S4; OPS-APPROVAL-0926의 `company_holidays`; SUPPLIER-EMAIL-0926; RULES-0927 §6). 공급사 강사 정원과 방 정원 중 작은 값을 썼고, 세션별 추가 강사 일비는 최종 견적상 없습니다(SUPPLIER-EMAIL-0926).

## 유지본에서 갱신할 가정과 다음 조치

선행 운영 메모 OPS-NOTE-V3는 현재 권한의 원천이 아니므로 다음과 같이 갱신해야 합니다. 메모의 인원 구성(P010 선택, P061 필수, P072 철회)은 승인 HR 로그 후 필수 60명 구성과 선택 12명 구성으로 바뀌었습니다. Cedar의 예산 추정 210,000원 + 1인당 6,500원은 최종 CEDAR 조건 240,000원 + 7,000원으로 대체합니다. 10월 9일 S4는 휴무일·미승인 제안이므로 제외합니다. 거래 ID 보존과 송금 재전송 중복 확인 원칙은 유효하며 이번 대사에서 각 ID의 대표·중복·역분을 행 단위로 분리했습니다(OPS-NOTE-V3; HR-APPROVED-0926 H01–H10; SUPPLIER-TERMS-FINAL-0926; SUPPLIER-EMAIL-0926; RULES-0927).

- **지금 진행 가능:** 박운영은 72명 최종 명단과 66명 배정/6명 대기 명단을 내부 검토하고 자료 초안을 준비합니다. 최시설은 S2/S3/S5/S6의 접근성·장비·실효 정원을 점검합니다. 정회계는 기존 미지급 787,600원과 신규 한도 965,000원을 이 파일 기준으로 유지합니다. 이들은 준비·대사 작업이며 외부 발송이나 확정 예약이 아닙니다(OPS-NOTE-V3의 담당 역할; OPS-APPROVAL-0926; RULES-0927 §8).
- **결재 필요:** 윤구매가 CEDAR 선택안을 상신하고 운영책임자가 공급사 선택 서명을 해야 합니다. 운영 목표일은 준비 첫 근무일 **2026-10-01 이전**, 늦어도 첫 세션 **2026-10-06 및 구매 실행 전에** 결재 완료입니다. 현재 상태는 미결로 둡니다(SUPPLIER-EMAIL-0926; OPS-APPROVAL-0926).
- **준비일:** 승인 일정의 가장 이른 세션 S2(10월 6일) 전 최근 세 회사 근무일은 **2026-10-01, 2026-10-02, 2026-10-05**입니다. 결재와 무관한 내부 명단 대사, 접근성 점검, 교육자료 준비를 이 날짜에 진행할 수 있습니다(RULES-0927 §8; OPS-APPROVAL-0926의 preparation rule).

선택 서명 전에는 예약·발주·지급·외부 전송을 하지 않습니다. 이 패키지는 서명 대기 상태의 검토 권고와 갱신 가능한 근거표이며, 승인 또는 실행 완료를 의미하지 않습니다.
