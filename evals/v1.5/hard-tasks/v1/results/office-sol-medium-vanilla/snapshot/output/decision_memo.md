## 배정과 선택 이유

승인 인사 변경 `H01`–`H10`을 적용한 최종 활성 인원은 72명으로 필수 60명, 선택 12명입니다. `H02`로 P010은 필수, `H03`으로 P061은 선택, `H04`로 P072는 활성 복귀했습니다. 제안 상태인 `H11`·`H12`는 적용하지 않았습니다(`HR-APPROVED-0926`, `HR-PROPOSAL-0927`). 세션 허용 목록은 `H06`–`H10`에서 해당 인원에 대해 통째로 교체했습니다.

선택 인원 중 P061·P062·P063·P065·P067·P068을 배정했습니다. **대기 명단은 P064·P066·P069·P070·P071·P072**입니다. 이 순서는 우선순위를 뜻하지 않습니다. 승인 제약에는 지역별 쿼터나 선택 인원 간 우선순위가 없습니다(`RULES-0927`). P064는 접근성 필요로 수정됐으나 허용 세션 S3·S6이 모두 비접근성이어서 현 승인 자료로는 배정할 수 없습니다(`R064`, `A064`, `H05`, 시설 S3/S6). 다른 대기 인원은 인원·예산·허용 세션을 함께 다시 검토할 때만 이동합니다. 대기자에게 비용을 계상하지 않았습니다.

접근성 필요 배정자 12명은 모두 접근 가능한 S2에 배정했습니다. S3와 S6은 접근 불가 시설이므로 해당 인원을 넣지 않았습니다(`FACILITY-0926`; `R001`–`R012`, `H01`, `H02`). S2·S3·S5·S6은 각각 다른 날짜에 있고 모두 승인 기간의 회사 근무일입니다. 10/9의 S4는 저렴하지만 제안 상태이며 회사 휴무일이어서 사용할 수 없습니다(`OPS-APPROVAL-0926`, 시설 S4, `SUPPLIER-EMAIL-0926`). 날짜별 코디네이터 1명 제약도 충족합니다.

승인 공급사와 승인 세션 조합을 필수 전원 충족 여부, 선택 인원 수, 비용 순서로 비교했습니다. 최종 배정 가능한 조합은 S2·S3·S5·S6이었고, 이 조합에서 CEDAR는 선택 6명/962,000원, ORCHID는 선택 4명/961,000원, LYRA는 선택 3명/964,000원입니다. ORCHID가 1,000원 저렴해도 선택 인원 두 명을 더 배정하는 목표가 먼저입니다. CEDAR-PILOT은 제안 상태이므로 비교 대상에서 제외했습니다(`SUPPLIER-TERMS-FINAL-0926`, `SUPPLIER-EMAIL-0926`, `RULES-0927`).

## 기존 유지 메모의 수정 사항과 실행 순서

`OPS-NOTE-V3`의 9/20 인사본과 P072 철회 가정은 위 승인 인사 로그로 갱신했습니다. 기존 CEDAR 추정가 210,000원 + 1인 6,500원은 최종 240,000원 + 1인 7,000원으로 바뀌었습니다(`SUPPLIER-TERMS-FINAL-0926`, `SUPPLIER-EMAIL-0926`). 기존 메모의 10/9 S4 시설 검토안은 승인 상태와 회사 휴무일 확인 결과 제외했습니다(`OPS-APPROVAL-0926`, 시설 S4). 재전송 전표 합산과 송금 취소 누락 위험은 거래 ID별 revision·중복·취소 대사로 처리했습니다(`P-D01`–`P-D04`, `P-R16`–`P-R18`, `RULES-0927`).

첫 교육일 10/6 전 가장 늦은 **회사 근무일 준비일은 10/1, 10/2, 10/5**입니다(`OPS-APPROVAL-0926`, `RULES-0927`). 운영책임자는 공급사 선택 서명을 완료하고, 윤구매는 그 서명 이후에만 공급사 발주 절차를 진행해야 합니다. 지금은 박운영이 승인 인사 변경을 반영한 내부 명단과 교육자료를 정리하고, 최시설이 S2/S5 접근성과 S3/S6 장비·정원을 내부 점검하며, 정회계가 `records.csv`와 `balances.csv`를 기준으로 미지급 준비금을 재확인할 수 있습니다(`OPS-NOTE-V3`, `SUPPLIER-EMAIL-0926`). 서명 전 예약·발주·지급·외부 발송은 실행하지 않았으며, 이 권고안도 실행 완료를 뜻하지 않습니다.
