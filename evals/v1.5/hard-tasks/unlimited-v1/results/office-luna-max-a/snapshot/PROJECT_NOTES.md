# 지역 직원 교육 운영 작업 메모

## 범위와 권한

- 합성 입력만 근거로 계획·대사 파일을 작성한다. 외부 회계·법률·휴일·공급사 정보는 추가하지 않는다.
- 적용 우선순위는 `inputs/12_domain_rules.md` 및 승인 제약, 승인 HR 변경과 최종 견적, 현재 원본 CSV, 유지본 메모 순이다. HR `pending`, 공급사 `pending`, 시설 `proposed`, 초안·중복·취소 거래는 규칙대로 처리한다.
- 공급사 선택 서명은 미결이다. 예약·발주·지급·외부 전송 또는 메시지는 실행하지 않는다. 독립 진행 가능한 대사·명단·접근성·교육자료 준비는 계속한다.
- 입력 파일은 수정하지 않는다. 개인 이름 대신 산출물 계약의 `person_id`와 출처 행 ID를 사용한다.

## 확인된 산출물과 체크포인트 — 2026-09-27

- 원본 표 데이터 263행을 읽었다. 송장·크레딧·지급 101개 물리 행을 `records.csv`에, 논리 송장 36개를 `balances.csv`에 보존했다.
- 현재 과거 잔액은 787,600원, 승인 총현금 한도는 1,752,600원, 신규 교육 예산은 965,000원이다. 제안된 추가 70,000원은 포함하지 않는다.
- 계획 권고는 CEDAR, S2·S3·S5·S6, 필수 60명과 선택 6명 배정이다. 총비용 962,000원, 잔액 3,000원. P064는 접근 가능 허용 세션이 없고, P068·P069·P070·P071·P072는 현 예산 한도로 대기한다. 선택 대기 순위는 정하지 않았다.
- 교육일은 2026-10-06, 2026-10-08, 2026-10-12, 2026-10-13이다. 준비일은 2026-10-01, 2026-10-02, 2026-10-05이다.
- 운영책임자의 공급사 선택 서명이 남았다. 그 서명 또는 실행이 완료됐다고 기록하지 않는다.
- 필수 파일은 `output/decision_memo.md`, `output/records.csv`, `output/balances.csv`, `output/plan.json`, `output/operations.xlsx`다. `build_outputs.py`는 입력에서 이 파일들을 다시 만드는 보조 스크립트다.

## 검증

- 생성 스크립트의 점검은 행 수, 거래 ID별 revision·중복·상태, 잔액 산식, HR 출처 집합, 배정·접근성·수용인원·예산·근무일, 4개 세션, 준비일, 다섯 파일 간 표 일치를 확인했다.
- 별도 읽기 점검으로 원본 거래 행과 대사 기록을 재비교하고, 36개 잔액의 대표 근거와 계산을 다시 확인했다. 승인된 공급사별 예산 내 최대 참석 인원과 엑셀 시트·셀 값·통화 서식도 재확인했다.
- 네트워크·외부 연락·예약·구매·지급·전송을 사용하지 않았다. 성능 측정은 실행하지 않았다.
