# 지역 직원 교육 출시 — 작업 메모

## 범위와 권한

- 근거는 `inputs/`의 12개 합성 파일로 한정한다. 원본 입력과 이전 운영 메모는 보존한다.
- 계획 추천과 내부 준비만 허용된다. 공급사 선택 서명 전에는 예약·발주·지급·외부 발송을 실행하지 않는다.
- pending HR 변경과 제안 예산은 적용하지 않는다. 새 증거를 받으면 해당 파일을 다시 대조한다.

## 현재 계산 결과

- 회계: 물리 송장·크레딧·지급 행 101개 보존, 논리 송장 36개 대사. 잔액 787,600원, 현금 상한 1,752,600원, 신규 교육 예산 965,000원.
- 인사: 승인 HR 변경 10건 반영. 최종 active 72명(필수 60, 선택 12명); 대기 변경 H11/H12는 반영하지 않음.
- 계획: CEDAR, S2/S3/S5/S6. 필수 60명과 선택 6명 배정. 비용 962,000원, 잔여 3,000원. 공급사 선택은 `supplier_selection_pending`.
- 준비일: 2026-10-01, 2026-10-02, 2026-10-05. S4는 제안 상태 및 회사 휴무일이라 제외.
- P064는 승인 접근성 필요와 S3/S6 전용 허용세션이 충돌하여 현재 배정 불가. 선택 대기자는 예산상 P068–P072; P064는 접근성/세션 적합성 문제로 별도 표시.

## 검토 가능한 결과물

`output/records.csv`, `output/balances.csv`, `output/plan.json`, `output/operations.xlsx`, `output/decision_memo.md`가 생성됐다. 독립 확인에서 원본 행 보존, 대표행/잔액 산식, HR·세션 출처 계보, 4개 세션의 참석자·용량, 총예산 및 CSV/JSON/Excel 일치를 통과했다.

## 다음 운영 단계

정회계는 대사 합계와 대표행을 검토하고, 박운영은 72명 최종 명단·대기명단 및 자료를 준비하며, 최시설은 S2/S3/S5/S6 접근성·장비 배치를 확인하고, 윤구매는 CEDAR 선택 서명안을 준비한다. 운영책임자의 선택 서명은 계약/예약 전에 필요하다. 문서에 공식 서명 마감은 없으므로 2026-09-30은 준비 개시 전 내부 권고 목표일이다. 서명 전에는 실행 권한으로 간주하지 않는다.
