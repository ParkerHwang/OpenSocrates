# Fixed primary review procedure

Review after outcome artifacts and calls are locked. Do not change a candidate,
run a new model judge or supply fixes to an outcome model. The primary knows the
condition; mark all semantic assessments provisional and unblinded, with human
scores null. Preserve contradictory deterministic and semantic findings separately.

## Coding

Record source paths/lines and concrete behavioral consequences for:

1. API contract and error handling: wrong methods, absent/null/zero distinctions,
   unknown keys, response shape and tenant boundaries.
2. State ownership: idempotency and business effects share one transaction; version
   checks, reversals and hold transitions preserve operation-specific preconditions.
3. Read/write transaction and resource lifetime: actual driver behavior, pool and
   journal choices, historical consistency and measured workloads. No universally
   preferred pool size or concurrency setting.
4. Reuse and maintainability: cohesive domain rules, useful pure functions and
   explicit effects, duplicated invariants, justified shared helpers and coupling.
   Do not score module count, line count or functional style as quality by itself.
5. Verification closure: provided caller/test intent, actual own-suite result,
   durable nontrivial domain tests, and claims in every public message. Distinguish
   a candidate defect, harness/rubric defect, missing evidence and reviewer error.

The output is a findings table and explicit unknowns, not an invented aggregate
architecture score. API correctness, repository checks, episode completion and
qualified performance remain separate columns.

## Korean office work

Use the unchanged five-dimension prose rubric with 0–4 anchors. Cite actual memo
lines, workbook coordinates, public-message indices and input source/row IDs.
Audit each material quantitative claim, including rejected alternatives, waiting
lists, corrected availability, cash reserve, units and equations, against source
or independently reproducible calculations. A correct plan/JSON score cannot
stand in for memo factuality. The number-format check is a separate diagnostic.

Assess questions and commitments across **all available public messages**, not
only the final message. When earlier public messages are missing, mark the relevant
conclusion unassessable. Preserve pending signature/authorization and evidence
limits. Semantic discrepancies do not alter the original 27-group score.

Report per tuple and domain with ties, regressions, improvements and missing
observations. Compare guide8/guide9 fresh pairs first; display historical vanilla,
released1.4 and old guide8 results only as dated context. No pooling, human-quality
claim, cost inference from text length or causal attribution to one guide change.
