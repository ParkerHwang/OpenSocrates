# IncidentOps S24 fixture preparation (pending browser capability decision)

`descriptor.json` is the standalone S task descriptor for the same six model/effort tuples × four arms = 24 proposed main-task episodes. It contains two units: an API/state/ownership design, followed by a Go backend and TypeScript frontend implementation in the existing modules. The combined task owns 13 paths, under the 16-path single-author interface. All public source files are bounded and the combined reference deliverables fit the native candidate limit. No outcome model call was made during fixture preparation.

Only `public/` is model-visible. Its starter already ingests basic events, persists and lists tenant incidents, has working filters, a multi-module Go/TypeScript split and a baseline test. It deliberately lacks the requested ledger reconciliation, effective policy/on-call selection, outbox lifecycle, derived summary, read-only UI actions and robust tests. The `private/controls/good/` tree is a complete positive control, never a subject input. The shared `../verify_external.py` checks native outputs only after the runner has overlaid exact candidate-owned bytes on a fresh marked disposable starter copy. Its trusted Python driver launches Go, TypeScript and Chromium under the runner's strict child policy and uses actual loopback API, SQLite restart, browser requests and state. Native checks remain read-only static/schema checks; they do not establish the external behavior.

`private/native_selftest.json` records the three good static checks with staged bytes unchanged. `private/controls/selftest.json` records a good functional/browser pass and six deliberately wrong implementations rejected at their intended checks: numeric policy maximum, tenant leak, obsolete outbox work, NORMAL instead of FULL synchronous mode, form-submit reload, and replay reported as new. `private/full_selftest.json` records the good reference's separate full workload: six fresh seeded databases, 60,000 API seed requests, 600 warm-up requests and 6,000 measured requests at concurrency 1/8/32 for filtered incident reads and unique event writes. It accounts for scheduled/completed/failed requests and validates final public state. The exact child policy canary in `private/isolation_canary.json` denies direct and symlink reads of the hidden S checker.

The macOS loopback Seatbelt rule has a verified `http.FileServer`/sendfile compatibility limit: a correct Go FileServer can advertise the full static asset but deliver only 512 bytes. The public starter uses ordinary bounded reads/writes and the good control passes Chromium under the same rule. `public/ENVIRONMENT.md` gives every arm the exact boundary. The external checker marks that transport signature `unassessable`, not a candidate semantic defect. This unresolved capability means S24 outcomes must remain pending a runner policy/qualification decision; a browser obligation left unknown cannot be silently counted as complete. Keep task correctness, native qualification, external integration and performance evidence distinct.

`private/FREEZE_PREP.json` records current preparation hashes and the pending status. O version 2 is the separate office subject task; the committed O version 1 packet is only validation controls. The S fixture has no interaction with real accounts, notifications, production databases or global memory/settings.
