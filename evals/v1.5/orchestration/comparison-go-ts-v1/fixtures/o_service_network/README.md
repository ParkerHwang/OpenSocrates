# O24 service-network fixture preparation

`descriptor.json` is the standalone O-only task descriptor. Its `task` value is the O projection of the shared comparison design: six model/effort tuples × four arms = 24 proposed outcomes. It contains the exact public source hashes, accepted contract, two units (`O-analysis` Go software production, then `O-document` Markdown production), four total owned paths, read-only native obligations, and the separate external qualifier command. This preparation has made no outcome model call.

Only `public/` belongs in role source roots. It contains a competent partial Go starter and the frozen synthetic data room; it does not contain the answer key or completed analysis. The `private/` tree holds an independently calculated Python oracle, a good Go/memo control, nine deliberately wrong controls, and receipts. Never stage those private files for a subject. The maintained source register hashes the six data files. The private oracle recomputes each metric from the frozen source independently of the good Go program, including event correction grain, date rather than maximum-value selection, missing versus zero, per-job integer rounding, facility shared cost, and scoped supplier sensitivity.

The public native checks require well-formed JSON/source hashes, parseable Go source, and a nonempty memo with evidence structure; they perform no build, execution, file write or network call. `private/native_selftest.json` records the good-control static checks on a disposable staging copy and confirms unchanged staged bytes. The external qualifier is the shared `../verify_external.py` with `--task O`, a fresh marked disposable candidate copy, the pinned local dependencies and the runner's strict candidate policy. The trusted Python grader reads private evidence; candidate Go execution is a sandboxed child that cannot read the oracle. `private/controls/selftest.json` records one good pass, nine intended wrong-control rejections and direct/symlink oracle-read denial under the exact child policy. Retained control copies and individual receipts are outside this worktree under a disposable run root.

The memo oracle checks every required portfolio's fixed/shared cost, assigned completed jobs, available/used minutes and feasibility against JSON pointers, plus SLA/backlog/credit/part-cost figures and relevant source IDs. The public decision record has `Recommendation`, `Criterion` and `Uncertainty` fields. A feasible single-site recommendation remains allowed when its coverage loss and validation need are explicit. The automated check cannot establish that a recommendation is operationally wise; a separate independent semantic review remains required.

`private/FREEZE_PREP.json` is the machine-readable preparation manifest. Its evidence level is fixture/control readiness only. Runner-owned pre-call checks must still verify the exact O descriptor, native product preparation, installed client, package and sandbox bytes before releasing any O outcome. Do not pool these controls with earlier evaluation outcomes.
