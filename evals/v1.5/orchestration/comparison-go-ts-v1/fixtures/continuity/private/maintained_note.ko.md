# 자료 정정과 범위 지정 삭제 이후의 유지 메모

승인되어 여전히 유효한 내용: Go 백엔드, TypeScript 프런트엔드, 가짜 발송함만 사용, 조회자 읽기 전용 권한, 대시보드 새로고침 뒤 키보드 포커스 유지. 이미 확정된 선택이다. 이전 자료에 의존한 P1 대기 시간 45분은 서비스 정책 2판이 1판을 대체했으므로 명시적으로 낡은 정보다. 정정된 숫자는 현재 자료에서 확인한다. 보라색 화면 분위기는 제안일 뿐 승인된 의도가 아니다. 담당자가 지정되지 않은 인수인계의 책임자는 보류 중이다. 범위가 정해진 임시 데모 지역 기록은 삭제되어 이 메모에 없다.
