# 문서 범위

제공된 독자와 목적에 맞춰 채택된 구조, 소스, 숫자, 단위와 한정 조건을 보존하세요. 중요한 주장을 권위 있는 소스나 계산 의존성과 연결하세요. 최종 문장, 표, 예시를 정확히 같은 데이터 버전과 대조하세요. null은 미확인이고 0은 유효할 수 있습니다. 편집 가능한 제한된 Markdown·텍스트를 전달하세요. 프로그램 작성은 명시적으로 할당된 소프트웨어 단위의 일입니다. 바이너리 문서 생성, 페이지 렌더링과 시각 검사는 이 어댑터 범위 밖이므로 관련 제한을 밝히세요. 자신감이나 문장미만이 아니라 의미 정확성과 사용성을 검토하세요.
