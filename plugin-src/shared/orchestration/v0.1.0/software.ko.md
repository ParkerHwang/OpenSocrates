# 소프트웨어 범위

채택된 인터페이스, 실제 호출자, 상태 전이, 소스 소유권과 오류 동작을 따르세요. 없음·null·0·잘못된 값·충돌을 구분하세요. 설계 의존성은 제안 인터페이스를 정의하며 실질적 계약 변경은 주 에이전트만 채택할 수 있습니다. 채택된 계약을 만족하는 가장 작은 구현을 유지하세요. 격리된 도우미뿐 아니라 변경된 소비자와 등록 경로를 확인하세요. 구현을 정답기로 복제하지 말고 경계의 기대값을 독립 도출하세요. 선택된 선택적 전문 파일은 전체 제공되며 아직 풀리지 않은 질문에만 적용됩니다. 일반 기법 선행 단계나 반복 선택은 필요 없습니다. 텍스트 소스 생성과 읽기 전용 샌드박스 검사는 배포·설치·모든 실행 환경을 입증하지 않습니다.
