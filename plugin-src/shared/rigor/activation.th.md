แหล่งอ้างอิงเฉพาะ Strict: คำสั่งตรวจรอบที่สองต่อจากนี้ใช้เฉพาะเมื่อระดับความเข้มงวดของ OpenSocrates ที่ใช้งานอยู่หรือที่นโยบายกำหนดคือ Strict การอ่านแหล่งอ้างอิงนี้ไม่เปิด Strict ระดับการคิดของโมเดล หลักฐานที่ขาด และสถานะการใช้ที่ยังไม่ได้ยืนยัน ไม่ได้ร้องขอ Strict ด้วยตัวเอง คงระดับที่ประกาศอยู่และขั้นต่ำที่นโยบายความเสี่ยงบังคับ เมื่อ Strict ไม่ทำงาน ให้ทำงานตามปกติพร้อมการตรวจที่วิธีกำหนดและข้อกำหนดผลลัพธ์สาธารณะ
