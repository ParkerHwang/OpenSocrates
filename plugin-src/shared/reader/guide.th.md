# เป้าหมายของผู้อ่านและการตัดสินที่นำไปใช้ได้

ใช้แนวทางนี้เมื่อสังเคราะห์เนื้อหาจากแหล่งข้อมูล อธิบายแนวคิดหรือการตัดสิน จัดโครงสร้างเอกสาร หรือเตรียมข้อความให้ผู้ที่ต้องเข้าใจและลงมือทำ แนวทางนี้อาจเพียงพอโดยไม่ต้องใช้วิธีตามต้นฉบับมาตรฐาน ความเหมาะสมของวิธีขึ้นอยู่กับการคิดที่จำเป็น ไม่ใช่ชื่อของสิ่งที่จะส่งมอบ ข้ามแนวทางนี้สำหรับขั้นตอนเชิงกลที่กำหนดไว้ นี่คือการตรวจการนำเสนอ ไม่ใช่วิธีให้เหตุผลอีกวิธีหนึ่ง

ระบุว่าใครจะใช้ผลลัพธ์ เขารู้อะไรแล้ว และต้องการการตัดสินหรือการกระทำถัดไปใด ใช้บริบทจริงของงาน อย่าสร้างแรงจูงใจของผู้เกี่ยวข้องขึ้นเองหรือขอให้ผู้ใช้ย้ำข้อมูลที่ได้ข้อยุติแล้ว ถามเฉพาะเมื่อคำตอบที่ขาดจะเปลี่ยนงานอย่างมีนัยสำคัญ

แยกข้อเท็จจริงที่ยืนยันแล้ว ข้ออ้างที่ระบุผู้กล่าว การตัดสิน สมมติฐาน และความเห็นต่างที่ยังไม่คลี่คลาย เชื่อมข้อสรุปเข้ากับหลักฐานและภูมิหลังที่ผู้อ่านต้องรู้ อธิบายว่าหน้าที่หรือความรู้ที่ต่างกันส่งผลต่อสถานการณ์อย่างไร โดยไม่เปลี่ยนจุดยืนของบุคคลเป็นข้อเท็จจริง คงความเห็นต่างที่สำคัญไว้แทนการปรับให้ดูเหมือนตกลงกันทั้งที่ไม่จริง

ข้อเท็จจริงที่ไม่ได้กล่าวถึงเป็นสิ่งที่ยังไม่ทราบ ไม่ใช่หลักฐานว่าสิ่งนั้นไม่มีอยู่ หากแหล่งข้อมูลไม่ได้ระบุผู้รับผิดชอบหรือเงื่อนไข ให้บอกว่าไม่ได้ให้ข้อมูลนั้น อย่าเรียกว่าไม่มีผู้รับผิดชอบ ใช้ไม่ได้ หรือยังไม่ได้จัดเตรียม การปฏิเสธชัดเจนของคนหนึ่งระบุข้อจำกัดของคนนั้น ไม่ใช่การไม่มีทางเลือกอื่น ในการติดตามผล ให้ปรับเฉพาะสิ่งที่หลักฐานใหม่เปลี่ยน คงข้อเท็จจริงอื่นที่ยืนยันแล้วและช่องว่างในแหล่งข้อมูลที่ยังไม่คลี่คลายพร้อมสถานะเดิม การยืนยันใหม่เรื่องหนึ่งไม่ทำให้สิ่งที่ไม่ทราบอีกเรื่องได้ข้อยุติ อย่าเปิดพิจารณาค่าหรือบทบาทที่ยืนยันในปัจจุบันใหม่เพียงเพราะข้อมูลเก่าต่างออกไป ถามเฉพาะข้อเท็จจริงที่ยังไม่คลี่คลายจริงและเปลี่ยนงาน

จัดลำดับข้อมูลตามเป้าหมายผู้อ่าน ให้บริบทพอเข้าใจว่าข้อสรุปตามมาจากอะไรและสิ่งใดยังไม่แน่นอน ระบุการกระทำถัดไปอย่างเป็นรูปธรรม ผู้รับผิดชอบเมื่อทราบ และเงื่อนไขที่กำกับการกระทำนั้นจริง อย่าเปลี่ยนหลักฐานเพิ่มเติมที่มีประโยชน์เป็นเงื่อนไขเบื้องต้นที่สร้างขึ้นเอง ปรับตามรูปแบบที่ผู้ใช้ขอโดยไม่บังคับหัวข้อ บรรยายวิธี หรือกำหนดความยาวตามอำเภอใจ

ร่างข้อความพูดแทนผู้เขียน คงการตัดสิน ความยินยอม และข้อผูกพันที่มีหลักฐานรองรับ อย่าเพิ่มคำสัญญา ทางเลือกสำรอง กำหนดเวลา หรือหน้าที่ที่ผู้ใช้หรือแหล่งข้อมูลไม่ได้อนุญาต ข้อเสนอแนะที่มีประโยชน์ไม่ใช่การตัดสินที่ยืนยันแล้ว แม้ในร่างที่จะไม่ส่ง หากเหมาะกับข้อความที่ขอ ให้ขอการตัดสินหรือกล่าวถึงความเป็นไปได้แบบมีเงื่อนไข แยกตัวเลือกที่ผู้เขียนอาจเลือกออกจากร่างพร้อมใช้ เว้นแต่ผู้ใช้ขอให้ใส่ข้อเสนอ จัดทำร่างที่มีหลักฐานรองรับโดยไม่เปิดเรื่องสิทธิ์ที่ได้ข้อยุติแล้วใหม่หรือบังคับให้ตอบทุกช่องว่างของแหล่งข้อมูล

ก่อนจบ ตรวจว่าผู้อ่านตามความเชื่อมโยงได้ รู้ว่าอะไรได้ข้อยุติ และใช้ผลลัพธ์ได้ ตรวจข้อผูกพันของทุกร่างและสิ่งที่ยังไม่ทราบทุกเรื่องที่ส่งต่อ เทียบกับแหล่งข้อมูลหรือคำสั่งผู้ใช้ คงผลลัพธ์สาธารณะที่จำเป็น แหล่งข้อมูล สถานะหลักฐาน เงื่อนไขหยุด และการผูกข้อสรุปกับหลักฐานของทุกวิธีที่ใช้ ถ้อยคำชัดเจนไม่อาจทดแทนการตัดสินที่มีหลักฐานรองรับหรือลบข้อจำกัดความสำเร็จ
