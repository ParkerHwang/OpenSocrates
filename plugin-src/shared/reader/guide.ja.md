# 読者の目的と使える判断

出典の資料をまとめる、意思決定を説明する、状況を理解して行動する必要がある人へのメッセージを作る際に、このガイドを使います。機械的作業では使いません。これは伝え方の点検であり、別の推論方法ではありません。

誰が結果を使い、その人が何をすでに知り、どのような判断や次の行動を必要としているかを整理します。実際の作業の文脈を使い、関係者の動機を作り出したり、確定した情報をユーザーに繰り返させたりしてはいけません。欠けている答えが作業を実質的に変える場合だけ質問します。

確立した事実、誰の主張かを明示した情報、意思決定、仮定、未解決の意見の相違を区別します。結論を、読者に必要な証拠と背景に結び付けます。責任や持っている知識の違いが状況にどう影響するかを説明し、その人の立場を事実に変えてはいけません。重要な意見の相違を残し、偽りの合意に整えてはいけません。

資料に記載のない事実は不明であり、現実に存在しないことの証拠にはなりません。出典が担当者や条件を示していなければ、その情報は提供されていないと述べます。未割り当て、利用不可、まだ手配されていないと断定してはいけません。ある人が明示的に断ったことは、その人の限界を示すだけで、代替案がないことを意味しません。続きの依頼では、新しい証拠が変える点だけを更新します。他の確立した事実と出典に残る未解決の情報不足は、従来の状態で引き継ぎます。一つの事実が新たに確認されても、別の未知の事実は解決しません。古い資料と違うという理由だけで現在確立している値や役割を問い直さず、作業を変える実際の未解決事項についてだけ尋ねます。

読者の目的に沿って情報を並べます。結論がなぜ導かれ、何がまだ不確かかを理解できるだけの背景を示します。具体的な次の行動、判明している場合は担当者、実際にその行動を左右する条件を述べます。追加で得ると役立つ証拠を、作り出した前提に変えてはいけません。ユーザーの指定形式に合わせ、見出し、方法の講義、任意の長さ制限を義務付けません。

メッセージの草稿は作者を代表して発言します。裏付けのある意思決定、同意、約束を保ち、ユーザーや出典が認めていない約束、予備の選択、期限、担当業務を加えてはいけません。送信しない草稿であっても、役立つ提案は確立した決定ではありません。依頼されたメッセージの目的に役立つなら、決定を求めるか、可能性を条件付きで説明します。ユーザーが提案を含めるよう依頼した場合を除き、作者が任意に選べる事項は、そのまま使える草稿から分けます。確定した許可を問い直したり、出典のすべての空白への回答を求めたりせず、裏付けのある草稿を完成させます。

仕上げる前に、読者が内容のつながりを理解し、確定した事項を見分け、結果を使えるかを点検します。各草稿の約束と引き継いだ未知の事項すべてを、出典またはユーザーの指示に照らして再確認します。適用した各方法の必須の公開結果、出典、証拠の状態、停止条件、根拠確認を保持します。明確な言葉は裏付けのある判断に代わるものではなく、完了範囲の限界をなくすものでもありません。
