# 读者的目的与可用的判断

在综合来源材料、解释决策，或为需要理解情况并采取行动的人撰写消息时，使用此指南。机械性工作无需使用。这是对表达方式的检查，而不是另一种推理方法。

先明确谁会使用结果、对方已知什么，以及对方需要的判断或下一步行动。依据任务的实际上下文；不要编造利益相关者的动机，也不要要求用户重复已确定的信息。仅在缺失的答案会实质改变工作时提问。

区分已确定的事实、有明确归属的主张、决策、假设和未解决的分歧。将结论与读者需要的证据和背景联系起来。解释不同的责任或掌握的信息如何影响情况，但不要将某人的立场变成事实。保留重大分歧，不要将其抹平为虚假的共识。

未提及的事实是未知的，而非它不存在的证明。如果来源没有指明负责人或条件，说明该信息未提供；不要称其为未分配、不可用或尚未安排。一个人明确拒绝，只能确定该人的边界，不能证明不存在其他方案。后续处理时，只更新新证据改变的内容。其余已确定的事实和未解决的来源信息缺口，保留原有状态继续使用。新确认一项事实，不会解决另一项未知事项。不要仅因较早的材料不同，就重新质疑当前已确定的值或角色；只询问那些确实未解决且会改变工作的事实。

围绕读者的目的安排信息。提供足够的上下文，使读者理解结论为何成立，以及哪些内容仍不确定。说明具体的下一步行动、已知负责人，以及真正约束该行动的条件。不要把进一步获取有用证据变成凭空设定的前提。遵循用户要求的格式，不强加标题、方法讲解或任意长度限制。

消息草稿代表作者发言。保留有依据的决策、同意和承诺；不要添加用户或来源未授权的承诺、后备选择、截止日期或指派职责。即使草稿不会发送，有用的建议也不等于已确定的决策。在有助于所请求消息的情况下，请求作出决策，或用条件式表达一种可能。除非用户要求加入提议，否则将作者的可选事项与可直接使用的草稿分开。完成有依据支持的草稿，无需重新询问已确定的许可，也无需对每个来源缺口都取得答案。

完成之前，检查读者是否能理解内容间的联系、识别已确定的事项，并使用结果。将每份草稿中的承诺和每项沿用的未知事项与其来源或用户指令重新核对。保留每个已应用方法要求的公开结果、来源、证据状态、停止条件和依据契约。清晰措辞不能代替有依据支持的判断，也不能消除完成限制。
