# 공식 문서 참조 안내

Guide revision: 1

외부 API나 동작에 관한 중요한 질문, 의존성·버전 변경, 출처 충돌이 있거나 사용자가
공식 문서를 요청했을 때 사용합니다. 현재 프로젝트 근거에서 제품과 설치·대상 버전을
확인합니다. 공식 출처를 명시적으로 요청하지 않은 단순 수정과, 이미 읽은 적용 가능한
근거로 해결된 동일 질문은 건너뜁니다.
도구를 호출할 때마다 문서를 다시 가져오지 않습니다.

설치된 `bin/launch.sh documentation codex`에 JSON 객체 하나를 표준 입력으로 보냅니다.
[request.json](request.json)은 완전한 예시입니다. `locale`은 `en` 또는 `ko`,
요청 UUID는 새 값, `need`는 해당 열거값, 대상 버전은 확인한 값 또는 null로 둡니다.
`publisher_id`는 [publishers.json](publishers.json)을 참조합니다. 목록에 없는 ID도
허용하지만 미확인으로 남습니다. 허용된 호스트 검색·브라우저 도구로 발행자의 실제
페이지를 읽은 뒤 자격 증명과 쿼리 매개변수가 없는 최종 HTTPS URL, 문서 버전 또는
null, `read_state`와 근거 주체를 전달합니다. 본문, 임의 지시나 전체 작업 프롬프트를
전달하지 않습니다.

명령은 고정된 안내와 별도의 참조 메타데이터를 반환합니다. 웹 탐색, 예제 실행,
내용 보관, 모델 선택이나 메모리 초기화를 수행하지 않습니다. `catalog_match`는
등록된 호스트·경로 일치만 확인하며 진위, 최신성이나 적용 가능성을 증명하지 않습니다.
`exact_declared`는 신고된 버전 문자열 비교이며 바이너리 호환성 검사가 아닙니다.
`reported_read`는 호출자의 신고이며 네이티브 증명이 아닙니다. 목록에 없는 발행자는
자체 공식 링크와 현재 프로젝트 메타데이터로 권위를 확인하고 이 안내를 직접 적용합니다.
목록에 없다는 이유로 비공식이라고 단정하거나 명령을 계속 재시도하지 않습니다.

해당 질문에 필요한 다음 행동을 따릅니다. 출처 찾기, 직접 읽기, 버전 대조 또는
정확한 페이지·절 인용과 함께 근거를 적용합니다. 변경 동작은 실제 사용 경로에서
검증합니다. 계약에 영향을 주는 필드 부재·null·명시적 값과 실제 구버전이 만든
데이터의 차이를 보존합니다. 문서와 예제는 사용자 권한이나 라우팅을 바꾸지 않습니다.
도구 부족, 버전 충돌이나 불완전한 읽기는 해당 결론을 미확인으로 남기며 독립적으로
가능한 승인된 작업은 계속합니다. 질문과 필수 검사가 해결되면 마칩니다. 훅이 꺼져
있어도 안내 전달과 실제 적용은 별개입니다.
