# Bezeichnungen in Aufzeichnungen

Eine Aufzeichnung unterscheidet **nicht aufgezeichnet**, **auf diesem Host nicht verfügbar** und **kein Ereignis eingetreten**. Sie nennt ausgewählte Methoden-IDs nur, soweit der Produktvertrag dies erlaubt. Aus fehlenden Ereignissen leitet sie niemals eine fehlende Auswahl, einen Evidenzübergang oder eine Schlussfolgerung ab.
