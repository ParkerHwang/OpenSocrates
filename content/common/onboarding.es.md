# Primeros pasos

OpenSocrates actúa de forma discreta de manera predeterminada. Interviene cuando un juicio necesita un alcance claro, el estado de la evidencia, una declaración de incertidumbre o una comprobación de finalización. Puedes solicitar un nivel de rigor mayor; para el juicio actual, el rigor solo puede aumentar.

Las acciones mecánicas siguen siendo mecánicas. Las solicitudes mixtas se separan para enrutar solo la parte que requiere juicio. El resultado es una tarjeta pública de conclusión (Conclusion Card), no una transcripción del razonamiento oculto.
