# Einstieg

OpenSocrates bleibt standardmäßig im Hintergrund. Es greift ein, wenn ein Urteil eine klare Grenze, einen Evidenzstatus, eine Angabe zur Unsicherheit oder eine Abschlussprüfung benötigt. Sie können eine höhere Strengestufe verlangen; für das aktuelle Urteil kann die Strenge nur steigen.

Mechanische Handlungen bleiben mechanisch. Gemischte Anfragen werden aufgeteilt, sodass nur der urteilsbezogene Teil geroutet wird. Das Ergebnis ist eine öffentliche Schlussfolgerungskarte, keine Mitschrift verborgener Denkprozesse.
